# Outline Planner — 학습 곡선 기반 구조 설계

좋은 기술서는 목차에서 승부가 갈린다. 이 스킬은 독자의 출발점에서 목표 지점까지
**끊기지 않는 학습 경로**를 만들고, 각 단원이 그 경로에서 정확히 한 칸을
전진하도록 아웃라인을 설계한다.

## 언제 쓰나

- 새 책/권/장의 목차를 처음 잡을 때
- 기존 자료(매뉴얼·블로그)를 책으로 재편성할 때
- 한 권이 너무 커져 권을 분할하거나, 장 순서를 재배치할 때

## 설계 절차

### 1. 좌표 정의
먼저 세 가지를 한 문장씩으로 못 박는다.
- **독자의 출발점**: 지금 무엇을 할 줄 아는가 (예: 터미널은 써봤지만 AI 코딩은 처음)
- **도착점**: 책을 덮을 때 혼자 무엇을 할 수 있어야 하는가
- **한 문장 약속**: 이 책이 독자에게 거는 단 하나의 약속

### 2. 마일스톤 역설계
도착점에서 출발점으로 거꾸로 짚어, 독자가 반드시 통과해야 할 **능력
마일스톤**을 5~9개 뽑는다. 각 마일스톤이 하나의 '부(Part)'가 된다.
순서 규칙: 앞 단원의 산출물이 다음 단원의 입력이 되도록 연결한다.

### 3. 장·절 배치
각 부를 장으로 쪼갠다. 장마다 다음 메타데이터를 채운다.

| 항목 | 내용 |
|------|------|
| 학습 목표 | 이 장을 마치면 독자가 할 수 있게 되는 것 (동사로) |
| 선수 지식 | 앞의 어느 장을 끝냈어야 하는가 |
| 핵심 개념 | 새로 도입하는 개념 3개 이내 |
| 실습 | 손으로 직접 해보는 것 (있다면) |
| 분량 | 예상 페이지/단어 수 |
| 함정 | 독자가 자주 막히는 지점과 대비 |

### 4. 인지 부하 점검
- 한 장에서 새 개념을 4개 이상 도입하면 쪼갠다.
- 난도 곡선이 급등하는 구간 앞에 '쉬어 가는' 실습/복습 장을 넣는다.
- 초급 단원에서는 '왜'보다 '어떻게'를, 고급 단원에서는 '왜'와 트레이드오프를.

### 5. 권 분할 (다권 구성 시)
- 권 사이의 경계는 **독자 정체성이 바뀌는 지점**에 둔다
  (예: "따라 하는 사람" → "스스로 설계하는 사람").
- 각 권은 독립적으로도 완결되게 하되, 다음 권으로의 다리를 마지막 장에 둔다.

## 출력 형식

아웃라인은 다음 구조의 마크다운으로 낸다.

```
# (책 제목)
> 한 문장 약속 / 대상 독자 / 끝낸 뒤 할 수 있는 일

## Part N. (마일스톤 이름)
### N-M. (장 제목)
- 학습 목표:
- 선수 지식:
- 핵심 개념:
- 실습:
- 함정:
- 분량:
```

## 품질 기준 (셀프 체크)

- [ ] 1장만 알아도 무언가 만들 수 있는가 (첫 성취까지의 거리가 짧은가)
- [ ] 각 장이 앞 장의 산출물을 쓰는가 (경로가 끊기지 않는가)
- [ ] 같은 개념이 여러 장에 흩어져 중복되지 않는가
- [ ] 권/부 경계가 독자의 성장 단계와 일치하는가
- [ ] 마지막 장이 '다음에 무엇을 할지'로 독자를 떠나보내는가

## 하지 말 것

- 주제를 백과사전식으로 나열하지 않는다. 경로가 먼저, 망라는 그다음.
- 저자가 쓰기 쉬운 순서가 아니라 **독자가 배우기 쉬운 순서**로 배치한다.
