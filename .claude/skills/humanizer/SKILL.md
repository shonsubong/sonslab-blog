# Humanizer — 사람다운 한국어 기술 글쓰기

AI가 생성한 한국어 원고는 일정한 냄새가 난다. 이 스킬은 그 냄새를 식별하고
제거해, 한 명의 실력 있는 한국어 저자가 직접 쓴 것처럼 읽히게 만든다.
교정 대상은 기술 도서·매뉴얼·블로그처럼 **정확성과 신뢰가 중요한 글**이다.

## 언제 쓰나

- 책/장/절 초안을 쓴 직후, 출판 품질로 끌어올릴 때
- 여러 챕터의 톤이 들쭉날쭉할 때 한 목소리로 통일할 때
- 번역투·상투구가 의심될 때 일괄 점검할 때

## 핵심 원칙

1. **정보는 보존, 표현만 교정한다.** 기술적 사실·코드·수치·명령어는 절대
   바꾸지 않는다. 바꾸는 것은 문장의 결뿐이다.
2. **저자는 한 사람이다.** "우리는", "여러분께서는" 같은 막연한 복수 대신
   독자에게 직접 말을 건다. 자신 있게 단정하고, 필요할 때만 단서를 단다.
3. **짧고 고른 호흡.** 모든 문장을 같은 길이로 만들지 않는다. 긴 설명 뒤에는
   짧은 문장으로 끊어 준다.

## 제거 대상 — AI 한국어의 전형적 신호

### 어휘·상투구
- "~에 있어서", "~을 통해", "~라고 할 수 있습니다", "~하는 것이 중요합니다"
- "결론적으로", "다시 말해", "즉," 의 남발
- "혁신적인", "강력한", "손쉽게", "단 몇 번의 클릭만으로" 같은 마케팅 과장
- "여러분", "독자분들께서는" 의 반복 → 필요한 곳에만
- 영어 직역투: "그것은 ~입니다(It is)", "~할 수 있게 해줍니다(allows you to)"

### 구조적 신호
- 모든 문단이 "첫째, 둘째, 셋째"로 시작
- 모든 절이 똑같이 [개념 정의 → 예시 → 요약] 3단 구조
- 불릿마다 같은 길이, 같은 어미
- 문단 끝마다 "~를 살펴보겠습니다 / 알아보겠습니다" 예고

### 톤
- 과한 친절(이모지·느낌표 남발), 또는 과한 격식
- 근거 없는 확신("반드시", "절대", "누구나")
- 같은 말 반복 요약(한 절에서 결론을 세 번 말함)

## 교정 절차

1. **소리 내어 읽기 테스트.** 한국어 개발자가 실제로 이렇게 말하는가?
   어색하면 표시한다.
2. **상투구 치환.** 위 목록을 훑어 직접적이고 구체적인 표현으로 바꾼다.
   - (전) "Claude Code를 통해 작업을 효율적으로 수행할 수 있습니다."
   - (후) "Claude Code에 시키면 이 작업이 몇 분으로 줄어든다."
3. **리듬 손보기.** 연속한 긴 문장 사이에 짧은 문장을 넣는다.
4. **구체화.** 추상적 형용사를 숫자·예시·실제 명령어로 교체한다.
5. **잉여 제거.** 같은 뜻을 반복하는 문장·요약을 한 번으로 줄인다.
6. **사실 보존 확인.** 코드·명령어·버전·수치가 1번과 동일한지 대조한다.

## 출력 형식

교정 시 다음을 함께 제시한다.
- 교정된 본문
- (요청 시) 주요 변경 사유 3~5줄 — 무엇을, 왜 바꿨는지
- 사실 보존 체크: 코드/명령어/수치 변경 없음 확인

## 하지 말 것

- 기술 용어를 어설픈 순화어로 바꾸지 않는다(예: "커밋"을 "맡기기"로).
- 코드 블록 안 내용은 손대지 않는다.
- 문장을 '사람답게' 만든다며 정확도를 떨어뜨리지 않는다. 정확성이 항상 우선.
