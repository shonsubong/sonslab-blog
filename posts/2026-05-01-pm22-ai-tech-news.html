OpenAI가 처음으로 AWS Bedrock에 깔렸다 — Moonshot은 같은 주에 FlashKDA로 커널을 풀었다

근로자의 날 하루를 책상에서 닫는다. 아침엔 애플 콜, 점심엔 Anthropic $900B, 오후엔 FSD v14.3.2랑 Kimi K2.6을 적었다. 같은 주에 묶이는 한 줄을 더 깔아두고 자야겠다. 모델 자체가 아니라, 모델이 어디 위에서 굴러가는가 의 결이 한 번 더 그어진 자리다.

OpenAI on Bedrock — 7년짜리 Azure 락이 풀린 자리

AWS 블로그에 4월 28일자로 풀린 라인. Amazon Bedrock 위에 GPT-5.5, GPT-5.4, gpt-oss-20b/120b, Codex CLI/데스크톱/VS Code 확장, 그리고 Bedrock Managed Agents 가 일제히 깔렸다. OpenAI 공식 페이지에 "AWS 환경에서 우리 모델을 같은 Bedrock API로 호출" 이라는 문장이 박혔다. 마이크로소프트 독점 7년이 4월 27일에 공식 종료 됐고, 정확히 하루 뒤에 AWS가 받은 그림.

엔지니어 자리에서 결을 잡으면 두 가지가 묶인다. 하나는 Bedrock Managed Agents. Neowin이 정리한 결대로 "OpenAI 하니스(harness) 위에서 Bedrock이 직접 에이전트를 매니지" * 한다. 즉, Anthropic의 Bedrock Agents — Claude 라인 위에 올라간 매니지드 에이전트 와 같은 SDK 패턴 위에 OpenAI가 들어왔다는 얘기다. Bedrock 안에서 Claude vs GPT를 같은 API 표면에서 바꿔 끼울 수 있는* 자리가 처음으로 열렸다.

다른 하나는 Codex on Bedrock. CLI·데스크톱·VS Code 확장이 동시에 풀렸다는 건, 기업 안에서 Claude Code를 굴리지 못하던 자리 — AWS 거버넌스·VPC·IAM·CloudTrail로 다 묶여야만 통과되는 그 보안 라인 — 에 Codex가 먼저 들어간다 는 신호다. 점심에 Anthropic Claude Code 런레이트가 $14B 라인까지 점프한 걸 적었는데, 반대편에서 OpenAI가 엔터프라이즈 자리를 AWS 거버넌스 위에 올려서 받아치는 그림이 같은 주에 같이 풀린 셈.

Martin Cid 정리대로 "이제 OpenAI는 한 클라우드의 손님이 아니다" 가 라인의 결이다. Databricks도 같은 주에 GPT-5.5/Codex를 Unity AI Gateway로 풀었다. AWS · Databricks · Azure · 그리고 OpenAI의 자체 인프라 — 4축이 동시에 깔린 결. 어제 새벽에 적은 "한 모델 한 칩 한 클라우드" 의 "한 클라우드" 자리가 가장 먼저 갈라진 자리다.

FlashKDA — Kimi의 커널이 오픈된 자리

같은 주에 결을 한 번 더 잡아주는 라인은 4월 30일에 Moonshot이 X로 던진 FlashKDA 오픈소스다. CUTLASS 기반 커널, Kimi Delta Attention(KDA) 구현, H20 위에서 prefill 1.72×~2.22× 가속, flash-linear-attention 라이브러리에 드롭인 백엔드로 자동 디스패치. GitHub에 MIT로 풀렸다.

오후 글에 적은 Kimi K2.6이 모델의 자리에서 오픈웨이트의 결을 그었다면, FlashKDA는 커널의 자리에서 같은 결을 한 번 더 그은 라인이다. MarkTechPost가 정리한 결대로, KDA는 gated DeltaNet에 채널별 게이팅을 더한 linear attention이다. 이걸 SM90+ (Hopper 라인 — H100/H20)에서 CUTLASS로 새로 짜서 full attention 대비 1M 컨텍스트에서 디코딩 6× 가속, KV 캐시 75% 감소 라는 라인이 Kimi Linear 위에서 그대로 깔린다.

엔지니어 자리에서 결을 잡으면 묘한 구도다. China가 H20에 묶여 있다 는 라인은 작년부터 깔려 있는 제약인데, Moonshot이 그 제약 위에서 가장 빠른 attention 커널을 직접 짜서 오픈 했다. NVIDIA가 H100/H200/B200 라인을 한 자리씩 올려가는 동안, H20에 최적화된 커널이 오픈소스로 풀리는 흐름은 long-context · 저비용 추론 자리에서 결을 만든다. 회사 안에선 보안 정책 때문에 못 깔지만, 개인 사이드 프로젝트로 H100 한 장 붙은 클라우드 인스턴스에 올려서 한 번 굴려보면 flash-linear-attention 자체에 어떻게 뚫고 들어가는지 가 손에 잡힌다.

Meta Muse Spark — contemplating mode 한 줄

야간 끝에 짧게 한 줄만 더. CNBC 영상 정리대로 4월 28일에 Meta가 Muse Spark의 contemplating mode 를 풀었다. 멀티 에이전트가 분담해서 리서치하고 한 줄로 합쳐 답을 내는 모드 — Anthropic의 Research, OpenAI의 Deep Research, Google의 Mariner 라인이랑 같은 자리에 들어온 답안이다. JPMorgan은 "Meta가 AI 대화로 돌아왔다" 라고 짚었는데, 4월 8일 발표 직후에 풀렸던 "Llama 오픈웨이트 노선에서 폐쇄형으로 선회" 라인이 contemplating mode 라는 첫 번째 디퍼런시에이터로 받쳐지는 결.

하루 닫기 직전 한 줄

오늘 하루가 모델 한 줄, 자본 한 줄, 클라우드 한 줄, 커널 한 줄 — AI 스택의 네 층이 같은 날 한 번씩 다시 그어진 자리였다. 점심에 Anthropic이 Claude Code 자리에서 OpenAI를 처음으로 위에 올랐다 고 적었는데, 같은 주에 OpenAI가 Bedrock 위로 올라타면서 클라우드 락을 풀었다. 한쪽이 한 자리를 잡는 동안 다른 쪽은 다른 자리를 푸는 — 이게 2026년 2분기의 톤인 것 같다. 근로자의 날 끝.
