Anthropic이 한 주 안에 세 칸을 그었다 — IPO·Glasswing·파트너 트랙

퇴근하고 집 들어와서 X 타임라인을 한 번 훑었다. 이번 주 월요일부터 수요일까지, Anthropic이 세 칸을 거의 동시에 그어 놓은 분기다. IPO S-1 비공개 제출 → Project Glasswing 확장 → Services Track·Partner Hub 공개. 한 회사가 사흘 안에 자본 라인·보안 라인·파트너 라인을 한꺼번에 깐 자리. 같은 주에 Microsoft가 Build에서 자체 모델 MAI-Thinking-1·MAI-Code-1-Flash를 공개한 줄이 옆에 박혀 있다. 오늘 저녁 자리 두 칸 정리.

Anthropic의 사흘 — IPO·Glasswing·Partner Network

월요일 자리부터. Anthropic 공식 발표와 TechCrunch 정리 기준 — 6월 1일에 Form S-1을 SEC에 비공개로 제출했다. 주식 수·가격·티커·상장일은 아직 안 정해진 자리. 다만 Yahoo Finance 정리 톤으로는 연환산 매출 run-rate가 $47B 수준까지 올라온 자리에서 던지는 카드다. 같은 주에 OpenAI가 5월 22일 자기 S-1을 던졌고 9월 상장을 목표로 잡았다는 CNBC 정리도 같이 박혔다. Claude vs GPT가 모델 라인이 아니라 공모주 시장에서 한 칸 더 벌어지는 분기다.

화요일에는 Project Glasswing 확장 발표가 났다. Help Net Security 정리와 TechCrunch 정리 기준 — Claude Mythos를 전력·수도·의료·통신·하드웨어 영역에 있는 150개 추가 조직, 15개국 이상까지 확장한 자리다. Mythos는 수천 개의 zero-day 취약점을 몇 주 안에 식별할 수 있는 사이버 능력 모델로 박혀 있고, 출시 이후 Glasswing 파트너들이 10,000개 이상의 high·critical 보안 결함을 찾아냈다는 톤이다. Apple·NVIDIA·Microsoft·CrowdStrike·Palo Alto Networks가 파트너 라인에 올라와 있다. Anthropic 본인들은 "6~12개월 안에 다른 AI 회사들도 Mythos급 모델을 가지게 될 것"이라는 줄을 같이 박았다. 공격용·방어용 양쪽 카드를 동시에 쥔 회사가 방어 라인에 먼저 한 칸 깔겠다는 톤이다.

수요일에는 Services Track·Partner Hub가 공개됐다. PYMNTS 정리 기준 — 컨설팅·SI 파트너를 Select / Preferred / Global Premier 3티어로 묶은 구조. Global Premier 자리에 올라오려면 공인 컨설턴트 1,000명 이상, 공동 배포 고객 100곳 이상(3개 이상 권역), 공개 사례 15건 이상이 필요하다. 3월에 $100M으로 시작한 Claude Partner Network에 40,000개 이상 회사가 신청, 10,000명 이상 컨설턴트가 인증을 받았다는 줄이 같이 박혔다. MCP 커넥터로 파트너가 자기 티어 상태를 Claude 안에서 직접 조회할 수 있게 한 자리가 디테일에서 무겁다. AI 회사가 "API 회사"에서 엔터프라이즈 채널 회사로 한 칸 옮겨가는 그림이다.

세 칸을 한 줄로 묶으면 — 돈(IPO), 보안(Glasswing), 채널(Partner) 세 칸을 사흘 안에 박은 자리다. 모델 한 줄로 이기는 시대가 아니라 인프라 한 줄로 자리잡는 시대라는 톤이 그대로 보인다.

Microsoft Build — MAI-Thinking-1·MAI-Code-1-Flash 자리

옆 라인에서 같이 깔린 게 Microsoft Build 자리. CNBC 정리 기준 — Microsoft의 AI Superintelligence 팀이 MAI-Thinking-1을 첫 번째 추론 모델로 공개했다. 낮은 토큰 비용에서 높은 효율을 노린 모델이라는 톤. 같은 자리에 MAI-Code-1-Flash도 박혔는데, 자연어 설명을 받아 앱·웹 소스코드를 생성하는 첫 코드 모델이다. Thurrott 정리에서는 "OpenAI 의존도를 한 칸 낮추겠다"는 톤을 명시적으로 적었다.

같은 주에 Google이 Gemini 3.5 Flash를 GA로 풀고 Gemini 앱·AI Mode 기본 모델로 박은 자리에, Microsoft도 자기 모델 라인을 한 칸 띄운 그림이다. Microsoft·Google이 Anthropic·OpenAI를 모델 라인에서 따라잡는다는 톤보다는, 모델 자체는 비용 라인으로 한 칸 내려가고, 위에 자기네 런타임(Copilot·Antigravity·Gemini Enterprise)을 쌓는다는 톤이다. 모델 한 줄이 상품에서 부품으로 한 칸 내려간 분기다.

X 타임라인 톤도 비슷하게 박혔다 — "이번 한 주, 가장 큰 뉴스는 모델이 아니라 모델을 둘러싼 런타임이었다." Anthropic이 IPO·보안·파트너 라인을 깔고, Microsoft·Google이 자기 모델로 외부 의존을 줄이는 — 같은 분기에 위(자본)와 아래(부품)가 동시에 정리되는 그림이다.

저녁 한 줄

이번 주 Anthropic 세 칸을 한 칸씩 떼서 보면 각각 흔한 카드처럼 보이는데, 사흘 안에 세 칸을 동시에 깐 게 무거운 자리다. 돈·보안·채널 세 줄을 한 번에 잡는 회사가 Claude Code MAX를 매달 $200 내고 굴리는 입장에서 — 다음 분기에 API 가격보다 엔터프라이즈 톤이 한 칸 먼저 움직일 자리다. 같은 주 Microsoft·Google이 자기 모델로 비용 라인을 낮추는 사이에, Anthropic은 모델 위 인프라를 깔고 있다. 라인이 한 칸씩 떨어진 자리.

내일 아침 자리에 Gemini 3.5 Pro GA 톤이 올라올지 한 칸 더 보고, 다시 정리한다.
