Anthropic이 Stainless를 인수했다 — OpenAI·Google이 쓰던 SDK 자리가 한쪽으로 묶이는 결

회사 버스가 화성을 막 빠져나와 수지 방향으로 결을 잡는다. 핸드폰을 굴려보니 새벽에 짚어둔 Agent SDK 크레딧 분리 결이 한 단 더 무거운 톤으로 박힌 자리가 있다. Anthropic이 Stainless를 인수했다는 결. The Information이 5월 12일에 먼저 흘려둔 결을 TechCrunch 라인이 어제 자리에 공식 확정 톤으로 받아냈고, Anthropic 공식 라인에서 같은 자리에 짧게 박아둔 결. 새벽 글의 6월 15일 크레딧 라인에 한 단을 더 얹어주는 결이다.

Stainless가 뭐였나 — OpenAPI 스펙에서 SDK가 떨어지는 자리

Stainless 자리는 결의 모양이 한 줄로 또렷하다. OpenAPI 스펙을 받으면 그 자리에서 Python·TypeScript·Kotlin·Go·Java 등의 production-ready SDK가 자동으로 떨어진다. API 결이 바뀌면 SDK 결도 같이 굴러간다. 사람 손으로 SDK 자리를 한 줄 한 줄 깎던 결을 AI 컴파일러가 대신하는 라인. 2022년에 풀린 스타트업이고, 2024년 12월 Series A 자리에서 $150M 밸류에 묶여 있었다.

여기서 무게가 박힌 자리는 한 줄이다 — Stainless는 OpenAI·Google·Cloudflare의 공식 SDK를 만들던 자리다. Anthropic 공식 라인도 같은 톤을 자기 자리에서 받아 들였다. 즉 OpenAI Python SDK 자리, Google Gemini SDK 자리, Cloudflare API 라이브러리 자리 — 프론티어 결의 메이저 SDK 결을 한 자리에서 같이 굴려온 회사. 이걸 경쟁사 한 곳이 통째로 사들였다는 결.

결의 무게가 박힌 자리 — 경쟁사 SDK 결을 거두는 결

TechCrunch 라인이 받아낸 결의 단가는 최소 $300M. 1년 반 전 밸류의 2배 자리. 자금 일부는 Anthropic 자기 주식 결로 굴러간 톤. 다만 결의 무게가 박힌 자리는 단가가 아니라 다음 한 줄이다 — Stainless 자리는 호스팅 결의 모든 제품 라인을 와인드다운한다. SDK 제너레이터 자리도 같이. 이미 만들어둔 SDK는 고객 결로 남고 자기들이 수정·확장할 권리도 그대로 남지만, 새로 한 줄 더 굴리는 자리는 6월·7월쯤이면 사실상 닫히는 결.

엔지니어 입장에서 솔직하게 한 단 짚어두면 — 이건 인수가 아니라 라인을 거두는 결에 가깝다. Anthropic 입장에서 결의 가치는 두 갈래로 나뉜다. 하나는 내부 결: MCP 서버 자리·Agent SDK 자리·Claude 자체의 클라이언트 라이브러리 자리 — 이 결을 그대로 깎아낼 사람 결과 도구 결을 한 번에 끌어오는 라인. 둘은 외부 결: OpenAI·Google이 그동안 외주로 굴려오던 SDK 자리가 한순간에 경쟁사 손 안에 묶여 있던 결로 박혔다는 톤. 둘 다 지금 시점에 풀려야 했던 결이다. 새벽 글에서 짚어둔 6월 15일 Agent SDK 크레딧 분리 결과 같은 라인 위에서, Anthropic이 에이전트 자리의 SDK 인프라를 자기 결로 쥐고 가겠다는 의지가 한 단 또렷해진 결.

투자자 관점에서 짧게 잠깐 짚어두면, 이번 결이 진짜 결의 무게가 박히는 자리는 OpenAI·Google이 다음 한 달 안에 어떻게 자기 SDK 결을 굴리는지다. 자체 SDK 팀을 새로 깔든, 다른 OpenAPI 자동화 결을 끌어오든, 한 단 손이 가는 결. 그리고 새벽에 짚어둔 Anthropic이 $950B 결과 같은 봄 자리에서, $300M 결로 경쟁사 SDK 자리를 끊는 결은 — 프론티어 결의 자본이 단순한 토큰 단가 자리가 아니라 인프라 결의 길목 자리로도 움직이기 시작했다는 톤. 새벽에 짚어둔 Opus 4.7 Fast의 $30/M·$150/M 단가 결도 같은 맥락 위에서 다시 읽힌다.

사이드 1 — 중국 오픈웨이트 코딩 결 네 갈래가 12일 안에 풀렸다

자리를 한 번 옮겨두면, 새벽 글에서 DeepSeek V4 한 갈래로만 잠깐 짚었던 결이 사실은 훨씬 더 결이 굵었던 톤이다. Abhishek Gautam 블로그 라인·Medium 결의 Can Demir 정리·Atlas Cloud 비교 라인이 같이 박은 톤 — 4월 7일부터 4월 24일 사이, 12일 자리 안에 중국 4개 랩이 오픈웨이트 코딩 모델 결을 줄줄이 풀었다. Z.ai의 GLM-5.1, MiniMax의 M2.7, Moonshot의 Kimi K2.6, DeepSeek의 V4. 새벽 자리에선 마지막 한 결만 박아뒀는데, 점심 자리 지나면서 X 타임라인이 이 네 결을 하나의 그림으로 묶기 시작했다.

GLM-5.1 자리는 754B 파라미터 MoE. 결의 무게가 박힌 자리는 멀티 스텝 툴 사용 결의 안정성. MiniMax M2.7 자리는 32개 전문가 중 7개 활성 결의 MoE에 1M 컨텍스트. Kimi K2.6 자리는 긴 세션 에이전트 결의 안정성에 K2.5 대비 결을 한 단 끌어올린 라인. 네 모델 결 모두 공통적으로 Claude Opus 단가의 1/3 자리 미만에서 굴러간다. 새벽에 짚어둔 DeepSeek V4 $0.14/M 결과 같은 톤. Latent Space 라인이 받은 결대로 MiniMax M2.7이 GLM-5와 비슷한 결의 자리에서 단가만 1/3로 깔린 톤이 가장 또렷하다.

엔지니어 입장에서 한 단 짚어두면 — 오픈웨이트 결의 코딩 자리가 12일 안에 네 갈래로 풀렸다는 건, 결의 다양성이 단순히 한 모델이 잘 나오는 자리가 아니라 생태계 결로 굴러가고 있다는 톤이다. 새벽 글에서 프론티어와 오픈웨이트 결의 거리가 코딩 자리에선 굉장히 가까워졌다고 박아둔 결이 12일 자리 안에 네 번 반복으로 확인된 셈. Anthropic이 Stainless 결로 SDK 자리의 자본 라인을 그으면서, 그 반대편에선 중국 랩들이 모델 자체의 결을 1/3 자리 단가로 풀고 있는 결이 봄 끝자락의 양극에 박힌 자리다.

사이드 2 — 테슬라 로보택시 39대, 텔아비브에서 머스크가 "FSD V15까지 기다린다"

같은 퇴근 버스 자리에서 짧게 한 줄 더 짚어두면, Not a Tesla App 라인·Automotive World 라인이 받은 결의 톤 — Tesla 무인 로보택시 자리가 39대까지 결로 굴러갔다. 4월 초 자리의 9대에서, 5월 초 자리의 26대를 거쳐서. Austin 27대, Dallas 5대, Houston 6대. 같은 결에서 Invezz 라인이 받은 결 — 5월 18일 텔아비브 Smart Mobility Summit 자리에서 머스크가 박은 한 줄은, "진짜 대규모 결은 FSD V15까지 기다린다"는 톤. V15 자리는 2027년 초가 박힌 라인. 그 사이엔 Phoenix·Miami·Orlando·Tampa·Las Vegas 같은 지오펜스 결의 도시 자리가 한 줄씩 풀리는 결.

Tesla 투자자 관점에서 잠깐 짚어두면, 결의 무게가 박힌 자리는 39대 결의 숫자가 아니라, 머스크가 "V15까지 기다린다"고 공식 자리에서 한 줄 박은 결이다. 즉 2027년 초까지는 로보택시 자리의 결이 한 도시당 두 자릿수 결로 천천히 굴러갈 가능성이 한 단 또렷해진 톤. 같은 봄 자리에서 Anthropic Stainless 결·중국 오픈웨이트 4갈래 결과 같이 놓고 보면, AI 자리의 결은 빨리 굴러가는데, AI가 운전대 자리로 들어오는 결은 한 단 더 천천히 굴러간다는 그림이 또렷해지는 결.

묶어두면

퇴근 버스 한 줄로 묶어두면 — Anthropic이 Stainless를 $300M+ 자리에 인수한 결이 새벽에 짚어둔 6월 15일 Agent SDK 크레딧 분리 라인과 같은 그림 위에 박혔고, 경쟁사 SDK 자리를 와인드다운 결로 거두는 톤까지 같이 굴러간다는 게 오늘 자리의 가장 묵직한 결. 같은 봄 자리에서 중국 오픈웨이트 4갈래 결이 프론티어 단가의 1/3 자리에서 풀린 그림과, 테슬라 로보택시 결이 FSD V15까지 기다린다는 한 줄이 같은 톤 안에서 같이 굴러간다. 그리고 9시간 뒤 자리에선 Google I/O 키노트가 풀린다 — 새벽·점심에서 짚어둔 결의 모양이 어떻게 박히는지는 내일 새벽 자리에서 한 번 더 정리해두면 된다.

회사 버스가 동탄 IC를 막 지나간다. 창밖이 5월 한낮의 결을 살짝 식히는 톤으로 한 단 부드러워졌고, 핸드폰 화면이 X 타임라인의 SDK 결과 코딩 모델 결 사이에서 한 줄씩 굴러간다. 집에 도착하면 개인 GitHub 자리에 묶어둔 사이드 결을 Stainless가 만들어둔 OpenAI SDK 결로 한 번 더 굴려본 다음, 그 결이 이제 Anthropic 결로 묶인다는 톤을 다시 느껴봐야겠다.
