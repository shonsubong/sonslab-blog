Anthropic이 SDK 자리를 따로 떼어 갈았다 — 6월 15일부터 Claude Code MAX 결의 절반이 다른 통장으로 옮겨간다

밤이다. 점심에 Gemini Spark, 오후에 Higgsfield Supercomputer를 짚으면서 에이전트 결이 단일 모델 자리에서 오케스트레이션 자리로 한 단 올라가는 톤을 두 번 적어뒀는데, 정작 밤에 가장 묵직하게 떨어진 결은 그 결을 과금 모델 자리에서 한 단 다시 짚어내는 그림이었다. Anthropic이 한국시간으로 오늘 새벽(미국 5월 14일)에 풀어둔 Agent SDK·claude -p 분리 공지. 6월 15일부터 Claude 구독은 인터랙티브 사용 자리에만 묶이고, 프로그래매틱 호출 자리는 별도 크레딧 풀로 떨어져 나간다. 그러니까 Claude Code MAX 20x 자리를 월 $200에 굴리고 있는 나 같은 개인 구독자 자리에서 보면, 6월 15일부터 그 결의 절반이 다른 통장으로 옮겨가는 그림이다.

무엇이 어디로 옮겨가는가

The Register 라인과 DevToolPicks 정리 라인, 그리고 X의 @ClaudeDevs 원 스레드를 묶어두면 결은 깔끔하게 두 통장으로 갈라진다.

구독 자리에 남는 결 (지금처럼 그대로): - 터미널·IDE에서 인터랙티브로 굴리는 Claude Code - claude.ai 웹·데스크톱·모바일 채팅 - Claude Cowork

새로 떨어져 나가는 결 (별도 크레딧 풀): - Claude Agent SDK 호출 - claude -p 헤드리스 모드 - Claude Code GitHub Actions - Agent SDK 위에 올라간 서드파티 (OpenClaw, Conductor, Zed, Jean 등)

크레딧 금액은 구독료와 1:1로 맞춰진다. Pro $20 구독이면 SDK 크레딧 $20, Max 5x $100이면 $100, Max 20x $200이면 $200. 매달 갱신되고, 남으면 그냥 소멸한다 — 다음 달로 안 넘어간다. 크레딧 풀이 바닥나면, extra usage 자리를 켜둔 사람은 API 정가(Sonnet 4.6 기준 입력 백만 토큰 $3·출력 백만 토큰 $15)로 흘러가고, 안 켜둔 사람은 그 자리에서 서비스가 끊긴다.

The Register가 잘 짚은 한 줄이 있다 — "customers seeking to get the full value from the new arrangement need to calibrate their programmatic usage to consume the full credit every month, no more and no less". 결국 남지도 모자라지도 않게 매달 SDK 자리를 굴려야 본전이라는 톤이다. 통장이 하나에서 둘로 갈라지면서, 한쪽이 너무 비면 손해, 너무 차도 인터랙티브 자리가 답답해지지 않는 대신 이쪽 자리가 막힌다.

왜 지금인가 — 6주 안에 세 번째 조정

이게 한 번에 떨어진 결이 아니라는 게 묘하다. DevToolPicks 라인이 정리해둔 타임라인을 보면, 6주 동안 정확히 세 번 손이 들어갔다.

  • 4월 4일: 서드파티 에이전트(OpenClaw 등) 구독 사용 통째 금지
  • 4월 21일: Pro 플랜에서 Claude Code 자리를 떼어내는 실험 (며칠 만에 철회)
  • 5월 14일: Agent SDK·claude -p 자리를 별도 크레딧 풀로 분리 ← 지금 여기

세 결이 가리키는 방향은 한 줄이다 — flat-rate 구독 자리가 에이전트형 워크로드를 감당하지 못하는 그림. 인터랙티브로 사람이 한 줄씩 던지던 결과, claude -p로 백그라운드에서 토큰을 분 단위로 태우는 결의 비용 구조가 완전히 다른데, 같은 통장에서 굴리면 한쪽이 다른 쪽을 잡아먹는다. The Register가 지적한 "Anthropic은 결국 흑자 자리를 보여야 한다"는 톤도 같은 줄에 박혀 있다.

Boris Cherny (Claude Code 책임자)는 더 직설적으로 박았다 — 서드파티 도구는 prompt cache 자리 바깥에서 굴러가서 "really hard to do sustainably". 1st-party 도구인 Claude Code·Cowork는 캐시 hit rate를 끌어올리도록 엔지니어링되어 있는데, 서드파티는 매번 컨텍스트를 처음부터 다시 처리한다는 그림이다.

개발자 반응 — "값은 그대론데, 가치는 1/25로 떨어졌다"

X 자리에서 결이 한쪽으로 기울었다. Theo Browne (T3.gg)이 던진 한 줄이 가장 또렷하다 — "Conductor·Zed·claude -p를 CI에서 굴리던 사람 입장에선 사실상 사용량이 25배 줄어든 셈". 본인이 운영하는 T3 Code 자리도 "이 자리에 맞춰 일부러 경험을 더 안 좋게 깎아야 할 판"이라고 했다.

Ben Hylak (Raindrop.ai CTO)이 던진 결은 더 본질을 찌른다 — "This is either really silly, or shows how bad of a spot Anthropic is in re: GPUs". Anthropic이 SpaceX Colossus 1 데이터센터 자리를 빌리는 딜까지 추가로 박은 직후라는 점을 묶어두면, GPU 자리가 여전히 빠듯하다는 신호로 읽힐 여지가 충분히 있다는 톤.

Anthropic 쪽 Lydia Hallie의 반박도 같이 박혀 있다 — "가격은 그대로다. 같은 구독, 같은 월정액, 인터랙티브 자리 한도 그대로. 프로그래매틱 자리는 $20~$200 included credit이 새로 붙은 것이지 추가로 내는 돈이 아니다". 두 결 다 기술적으로 맞다. 가격은 안 올랐다. 다만 프로그래매틱 자리를 빡세게 쓰던 사람 입장의 결에서 보면, 같은 가격에 받던 가치가 한 단 깎인 그림이다.

내 결 — Max 20x $200 자리에서 어떻게 굴릴 건지

회사 자리에선 Claude Code를 못 굴린다 (보안 정책). 집 자리, 그러니까 개인 핸드폰·개인 PC 자리에서만 굴리는 결인데, 그래도 6월 15일 자리는 한 번 짚고 넘어가야 한다. 내 결의 사용 패턴을 솔직하게 까보면 두 결이 섞여 있다.

인터랙티브 자리 — 주말 새벽이나 퇴근 후 개인 프로젝트 자리에서 "이 함수 좀 짚어줘", "이 자리 리팩토링 해줘" 하는 결. 이건 6월 15일 이후로 변동 없다. 구독 자리 그대로 굴러간다.

프로그래매틱 자리 — claude -p 위에 작은 자동화 결 몇 개 (블로그 빌드 스크립트, 개인 README 자동 정리, 가끔 GitHub Actions 자리), 그리고 간헐적으로 OpenClaw 같은 서드파티 결을 시험해보는 자리. 이쪽 자리가 $200 크레딧 풀로 빠지는 그림.

대략 머릿속 계산을 굴려보면, Sonnet 4.6 기준 $200 크레딧은 입력 약 66M 토큰 또는 출력 약 13M 토큰 수준이다. 인터랙티브 자리만 굴리던 사람 입장에선 남으면 그냥 소멸. 프로그래매틱 자리를 헤비하게 굴리던 사람 입장에선 훨씬 빨리 바닥난다. 내 자리는 가운데 어디쯤 박혀 있는데, 6월 한 달은 그냥 굴려보고 7월부터 남는 결을 일부러 채우는 결로 자동화를 좀 더 박을지, 바닥나는 결이면 일부 자리를 API 키 직접 자리로 옮길지 결정해야 할 그림이다.

결의 본질 — 구독은 인터랙티브 자리로, 자동화는 API 자리로

DevToolPicks 라인이 마지막에 박아둔 한 줄이 결의 본질을 가장 정확하게 짚어낸다 — "For shared production workflows, move to an API key. The Developer Platform gives you pay-as-you-go billing without per-user credit ceilings". Anthropic이 6주에 걸쳐 그어두는 선이 점점 또렷해진다.

  • 구독 = 사람이 직접 굴리는 인터랙티브 자리
  • API = 기계가 굴리는 프로그래매틱·프로덕션 자리

flat-rate 구독으로 agentic workflow의 비용 구조를 덮는 자리는 더 이상 굴러가지 않는다는 결이 결국 산업 전체에 떨어지는 그림이다. GitHub Copilot도 비슷한 결로 움직이고 있다는 점을 같이 묶어두면, AI 코딩 어시스턴트 시장 전체가 "무제한 자리 → 토큰 기반 자리" 한 단 위로 통째로 옮겨가는 톤이다.

내일 새벽엔 Cerebras IPO ($66B) 자리도 한 번 짚어야 한다. 같은 결, 다른 자리. AI 자리가 flat-rate 구독도 commodity GPU 자리도 더 이상 흔들리지 않는 자리로 빠르게 굳어가고 있다는 톤이 어디서나 동시에 박힌다.

오늘은 여기서 끊는다. 5월 14일은 내 개인 통장 자리에 가장 직접적으로 떨어진 하루였다.
