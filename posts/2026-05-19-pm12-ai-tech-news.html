Microsoft MDASH가 88.45점으로 Mythos·GPT-5.5를 제쳤다 — 사이버 AI 자리에 세 번째 라인이 깔렸다

점심시간 회사 휴게실에서 X 타임라인을 굴려보는데, 결의 자리가 한 단 또렷하게 박혔다. 새벽에 짚어둔 Daybreak·Mythos 두 갈래 위에 Microsoft MDASH가 세 번째 라인으로 올라온 톤. 5월 12일 자리에 풀린 결인데, CyberGym 벤치 결의 숫자 자리가 이제야 X 자리에서 한 단씩 굴러간다. 새벽 글에서 오픈소스 코드의 결과 내부 레거시 코드의 결을 갈라뒀던 자리에 — Microsoft가 정확히 내부 결 쪽으로 라인을 깔았다.

MDASH — 100개 에이전트가 디베이트로 결을 가르는 자리

Microsoft Security 블로그 라인이 5월 12일에 박아둔 톤이 또렷하다. MDASH (Microsoft Defense Agentic Scanning Harness). 100개가 넘는 전문화된 에이전트가 프론티어 모델과 distilled 모델을 앙상블로 묶어서, 발견 → 디베이트 → 검증 자리를 끝까지 굴리는 결. 이름이 길지만 핵심은 단순하다 — 한 모델이 한 번 찍어내는 결이 아니라, 여러 에이전트가 서로 반박해가며 가짜 양성을 떨궈내는 자리.

GeekWire 라인·Neowin 라인이 같이 받은 결은 더 단순하다 — CyberGym 벤치마크에서 88.45점, 리더보드 1위. 1,507개 실제 취약점 재현 자리에서. 같은 표 위에서 Anthropic Mythos와 OpenAI GPT-5.5가 그 아래 자리에 박혔다. 새벽에 짚어둔 Mythos가 Firefox 자리에 271개 패치를 찍은 결과 같은 라인 위에서, 이번엔 Microsoft가 한 단 위에 자기 라인을 깔았다는 톤.

다만 정직하게 짚어둘 결이 한 줄 더 있다. Help Net Security 라인이 끝줄에 박아둔 톤 — CyberGym 점수는 모두 자기 신고 결이다. 벤치 코드 자리는 공개돼 있지만, 어느 한쪽도 다른 쪽의 점수를 독립적으로 검증한 자리는 아직 없다. 새벽 결의 "271개 패치 = zero-day" 논쟁과 같은 라인 위에서, 사이버 AI 자리의 숫자 결은 늘 한 단 의심하고 받는 게 맞다.

16개 Windows CVE — 결의 무게가 실제로 박힌 자리

벤치 결만 갖고는 무게가 안 박힌다. 정작 결의 무게가 박힌 자리는 Help Net Security 라인이 짚은 MDASH가 실제로 Windows 네트워킹·인증 스택에서 16개의 새 결함을 잡은 톤에 있다. 그중 4개가 Critical RCE. Windows kernel TCP/IP 스택 결과 IKEv2 서비스 결에 박힌 자리. 새벽 글에서 짚었던 내부 자리의 레거시 코드 결이 정확히 이 자리다. Firefox 30M+ 라인의 오픈소스 결과 달리, Windows 네트워킹 스택은 수십 년 묵은 내부 결. 그 결에서 4개의 Critical RCE가 한 시스템에서 잡혔다는 톤이 한 단 무겁다.

엔지니어 입장에서 솔직하게 짚어두면 — 지금 사이버 AI 결의 두 갈래가 명확하게 갈렸다. 한쪽은 Mythos·Daybreak이 외부 클라이언트 코드 결을 도는 라인, 다른 한쪽은 MDASH가 자기 OS 결의 안쪽을 직접 도는 라인. Microsoft 입장에선 공급자가 자기 코드를 자기가 도는 결의 보안 자리에 결정적으로 우위가 있다. Windows 빌드 시스템 결·심볼 결·내부 fuzz 코퍼스 결 — 외부 결의 어느 누구도 그 자리에 같은 깊이로 들어갈 수 없는 결이다. 새벽에 짚어둔 내부 결의 진짜 시험대는 이 자리에서 한 번 맞은 셈.

사이드 1 — ChatGPT가 은행 계좌 자리에 들어왔다

자리를 한 번 옮겨두면, 어제 자리에 OpenAI가 박은 결이 한 단 묵직하다. Dataconomy 라인·gHacks 라인이 5월 18일에 받은 톤 — ChatGPT Personal Finance Preview. ChatGPT Pro 자리·미국 자리·웹과 iOS 자리 한정으로 풀린 결. 핵심은 사용자가 자기 은행 계좌를 ChatGPT에 직접 연결한다는 자리. TechCrunch 라인이 짚은 톤대로 Plaid 결을 거치고, 12,000개 금융기관 자리에 묶여 있다 — Schwab·Fidelity·Chase·Robinhood·American Express·Capital One 라인까지.

모델 자리는 GPT-5.5 Thinking. OpenAI 내부 벤치에서 개인 재무 자리 100점 만점에 82.5점 결로 박혔다. 결의 무게가 박힌 자리는 두 갈래다. 하나는 대시보드 결로 잔액·지출 결을 보여주는 라인. 둘은 실제 계좌 데이터 결을 갖고 묻고 답하는 라인. 다만 American Banker 라인이 짚은 톤대로 ChatGPT는 완전한 계좌번호 자리를 볼 수 없고, 계좌에 변경을 가할 수도 없는 결. 읽기 전용 자리에 묶인 라인.

투자자 관점에서 잠깐 짚어두면, 결의 무게가 박힌 자리는 OpenAI가 결국 소비자 자리에서 거래 데이터 결로 들어왔다는 톤이다. Plaid 결을 거친다는 건 Intuit·Mint·Rocket Money 결과 같은 자리에서 굴러간다는 결. AI 어시스턴트 결이 광고 자리가 아니라 개인 금융 데이터 자리로 수익화 라인을 그리는 결의 첫 발이라고 봐도 무리가 아닌 톤. 새벽 글에서 짚어둔 Anthropic이 $950B 결에 묶인 톤과 같은 봄 자리에서, OpenAI도 프리미엄 결의 사용자 한 명당 결의 가치를 한 단 더 끌어올리는 라인에 박힌 자리다. 다만 은행 계좌 자리를 AI한테 여는 결에 대한 보안 우려가 같이 박힐 결이라, Trusted Access·MDASH 결과 같은 라인 위에서 같이 굴러갈 결이기도 하다.

사이드 2 — Google I/O 키노트가 14시간 앞

같은 점심 자리에서 잠깐만 더 짚어두면, Google I/O 2026 키노트가 한국시간 오늘 밤 수요일 새벽 2시 자리에 박힌다. Google I/O 공식 라인·Android Central 라인이 받은 톤 그대로 10AM PT 자리. 새벽 글에서 짚어둔 Gemini Omni 결·Aluminum OS 결·Android XR 안경 결에 더해, AIxploria 라인이 추가로 받은 톤이 한 단 무겁다 — Gemini Spark. 에이전트 자리의 새 브랜딩 결로 받은편지함 정리·미팅 브리프 자리 같은 다단계 결을 자동으로 굴리는 라인.

새벽 글에서 미리 짚어둔 세 자리(Omni·Aluminum·XR)에 Gemini Spark가 네 번째 자리로 박힐 결이다. Anthropic Agent SDK 크레딧 분리 결·OpenAI Personal Finance 결과 같은 봄 자리에서, Google이 에이전트 결의 자기 라인을 어떻게 깔지가 결의 무게를 가른다. 점심에 미리 짚어둘 결은 — 오늘 밤 키노트에서 Gemini Spark가 Claude Agent SDK 결·ChatGPT Pro Personal Finance 결 사이에 어느 자리에 박히는지. 14시간 뒤면 풀린다.

묶어두면

점심 한 줄로 묶어두면 — Microsoft MDASH가 사이버 AI 자리에 세 번째 라인을 깔았고, 새벽에 짚어둔 Mythos·Daybreak 두 갈래 위에서 정확히 내부 OS 결의 쪽으로 무게중심을 옮긴 톤. 88.45점 결의 자기 신고 자리는 한 단 의심하고 받되, Windows 네트워킹 스택에서 4개의 Critical RCE를 잡은 결은 결의 무게가 실제로 박힌 자리다. ChatGPT가 Plaid 결로 은행 계좌 자리에 들어온 결도 같은 봄에 같이 굴러가고, 14시간 뒤 Google I/O 키노트가 Gemini Spark까지 묶어서 자리를 한 번 더 그릴 결.

회사 휴게실 자리에서 점심 결을 마무리해야겠다. 오후 자리에 반도체 영상처리 결이 또 한 단 묵직하게 박힐 결이고, 퇴근 버스 자리에서 오후 사이에 풀린 결들 한 번 더 굴려둬야겠다. 화성 자리 창밖이 봄 한낮 결로 한 단 환하다.
