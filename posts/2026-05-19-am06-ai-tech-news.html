Claude Opus 4.7 Fast가 정식 결로 박혔고, Agent SDK가 별도 크레딧으로 떨어졌다 — 한 달 $200 자리의 그림이 한 단 다시 그려지는 봄 끝자락

화요일 새벽이다. 회사 버스 시각은 아직 한참 남았고, 거실 불을 켜자마자 핸드폰을 굴려보니 X 타임라인이 Google I/O 키노트 자리가 한국시간 내일 새벽 2시라는 카운트다운 결로 한쪽이 채워져 있다. 24시간도 안 남은 자리. 다만 키노트 결은 키노트가 풀리고 나서 짚어두면 되고, 새벽에 한 단 묵직하게 박힌 결은 따로 있다 — Anthropic이 지난주에 풀어둔 두 가지 결의 무게가 이제야 실감으로 박힌 톤.

Opus 4.7 Fast — 2.5배 속도 자리에 6배 단가가 박힌 결

Anthropic 공식 라인에서 5월 12일 자리에 박아둔 Claude Opus 4.7은 결의 모양이 한 단 또렷하다. Fast 모드. OpenRouter 라인·BuildFastWithAI 라인이 받은 톤을 묶어두면 — 동일 모델 품질, 동일 1M 컨텍스트 자리에서 출력 토큰 결만 2.5배 빠르게 굴러간다. 14일부터는 Fast 모드의 기본 자리가 Opus 4.7로 박혔고, Vercel AI Gateway·Cursor·Windsurf·v0·Warp까지 같은 자리에 풀린 결.

여기서 결의 무게가 박힌 자리는 단가다. 일반 Opus 4.7 자리가 $5/M 입력·$25/M 출력인데, Fast 모드 자리는 $30/M 입력·$150/M 출력. 6배 단가. 같은 품질·같은 컨텍스트 자리에서 오직 토큰이 나오는 속도 결만 바꾸려고 6배 단가를 깔아야 하는 자리. 엔지니어 입장에서 솔직하게 한 줄 박아두면 — 대화형 자리에선 한 결도 가까이 안 가는 게 맞다. 사람 자리는 어차피 읽는 속도가 토큰 결을 못 따라간다. 정작 Fast 모드가 결의 자리를 가지는 톤은 에이전트 자리 — 토큰이 토큰을 부르고 결이 결을 부르는 자리에서, 한 사이클 결을 0.4초 자리로 줄이는 결이 전체 워크플로우 결의 무게를 한 단 다르게 그리는 자리다. Vercel 체인지로그 라인이 받은 톤도 같은 라인 위에 있다 — 오케스트레이션 자리에서 사이클이 짧아지면 같은 시간 안에 단계가 더 많이 굴러간다.

그리고 6월 15일 — Agent SDK가 별도 크레딧 자리로 떨어진다

같이 묶어둘 결이 한 단 더 묵직하다. InfoWorld 라인·The New Stack 라인이 같이 박은 톤 — 6월 15일 자리부터 Claude Agent SDK·claude -p 자리·Claude Code GitHub Actions·서드파티 에이전트 결이 구독 자리의 사용량 풀에서 통째로 떨어진다. 구독 자리는 Claude.ai·Claude Code·Cowork 같은 대화형 자리만 남고, 프로그래매틱 자리는 별도 Agent SDK Credit pool로 갈라진 결.

크레딧 자리는 Anthropic 도움말 라인에 박힌 톤이 또렷하다 — Pro $20 / Max 5x $100 / Max 20x $200. 매월 자리에서 리셋, 롤오버 자리 없음. 결의 무게가 박힌 자리는 Max 20x 구독 결로 $200 자리를 굴리던 사람 입장에서 — 그 $200이 사실상 두 갈래로 갈라진 톤. 대화형 자리의 결은 그대로 굴러가지만, 그동안 Max 한도 자리에 묶여서 굴러가던 백그라운드 에이전트 자리는 별도 크레딧 결에서만 굴러간다. 풀 API 단가로 계산되는 결이라, 익숙한 "Max 한도 안에서 마음껏 굴리는 결"은 6월 15일 자리 너머에선 그 모양 그대로는 안 굴러간다.

Zed 블로그 라인이 받은 톤대로 IDE 결 안의 에이전트가 Anthropic의 정의 자리에서 어디까지 "프로그래매틱"으로 분류되는지가 결의 무게를 가른다. 대화형 자리(채팅 UI에서 한 번 누르고 답이 돌아오는 결) vs 프로그래매틱 자리(스크립트 결·CI 결·자동화 결). 회사 자리에선 어차피 Claude Code 자체를 못 굴리니까(보안 정책) 이 결이 회사 톤에 박힐 일은 없지만, 집 자리·주말 자리·개인 사이드 결로 굴려두던 자리는 한 번 그림을 다시 그려야 하는 톤이다. 새벽에 한 결만 박아두면 — Max 결로 백그라운드 결을 굴리던 자리는 6월 15일 전에 그 결을 한 번 끊어두고, $200 자리의 크레딧 결이 어디까지 가는지부터 재본 다음에 다시 풀어두는 게 맞다.

사이드 — 오픈웨이트 결의 무게가 한 단 더 또렷해진 봄

자리를 한 번 옮겨두면, 같은 봄 자리에 묶일 결이 한 단 더 있다. MindStudio 라인·Fortune 라인이 4월 24일 자리에 박은 DeepSeek V4 결, Mistral 공식 라인이 4월 29일에 풀어둔 Mistral Medium 3.5 결, 그리고 2월 자리에 풀려서 봄 자리에서 한 단 더 자리잡은 Qwen 3.5 결. 셋을 같이 묶어두면 결의 그림이 또렷하다.

DeepSeek V4-Pro 자리는 1.6T 파라미터(활성 49B) MoE, 1M 컨텍스트, MIT 라이선스. LiveCodeBench 자리에선 93.5% 라인이 박혔고, 같은 자리의 Claude·GPT-5.5 결을 오픈웨이트 결이 처음으로 넘어선 톤. 토큰 단가 자리는 $0.14/M. Mistral Medium 3.5 자리는 128B 단일 결에 instruction·reasoning·coding을 한 자리에 묶었고, MarkTechPost 라인이 받은 톤대로 SWE-Bench Verified 자리에서 77.6%. Le Chat의 Work 모드 결·Vibe의 remote 코딩 결까지 같은 라인 위에서 굴러간다. Qwen 3.5 자리는 397B MoE / 256K 컨텍스트 / Apache 2.0 / 201개 언어 / 비전 결까지 묶인 라인.

엔지니어 입장에서 솔직하게 한 단 더 짚어두면 — 프론티어 결과 오픈웨이트 결의 거리가 코딩·에이전트 자리에선 이미 굉장히 가까워진 톤이다. Opus 4.7 Fast의 $30/M·$150/M 단가 결과 DeepSeek V4의 $0.14/M 결이 같은 표 위에 박힌 자리는 200배 결의 가격 차이. 결의 모양이 같지 않다는 건 분명하지만, 코딩·에이전트 자리에서 그 200배 결 만큼의 결의 차이가 있는지는 자리마다 점점 더 정직하게 따져야 하는 톤. 어제 밤에 묶어둔 Hermes Agent + Qwen 3.6 + DGX Spark 결과 같은 라인 위에 있다 — 오픈웨이트 + 로컬 자리가 어디까지 정직하게 굴러가는지가 봄 끝자락의 결을 가르는 자리다.

묶어두면

새벽 한 줄로 묶어두면 — Opus 4.7 Fast 결과 Agent SDK 크레딧 분리 결이 봄 끝자락에 박힌 가장 묵직한 자리고, 그 옆자리에 DeepSeek V4·Mistral Medium 3.5·Qwen 3.5 결이 오픈웨이트 결의 무게를 한 단 더 또렷하게 깔아둔 톤. 24시간 안에 Google I/O 키노트 자리에서 Gemini 새 결이 풀리면서 이 그림 위에 한 단이 더 그려질 결이다. 새벽에 미리 짚어둘 자리는 — 오늘 밤 키노트에서 (1) Gemini 새 버전 결이 Opus 4.7·GPT-5.5·Mythos 결의 어디 자리에 박히는지 (2) Aluminum OS·Android XR 자리가 디바이스 결로 풀리는지 (3) 에이전트 자리의 결이 어디까지 또렷해지는지. 이 세 자리가 봄 끝자락의 결을 가른다.

회사 버스 시각이 슬슬 가까워진다. 어제 새벽에 짚어둔 Daybreak·Mythos 결과 오늘 새벽에 박은 Opus 4.7 Fast·Agent SDK 결이 같은 라인 위에서 굴러가고, 24시간 뒤 자리에서 Google이 한 단을 더 그릴 결. 화성행 버스 자리에서 X 타임라인이나 한 번 더 굴려둬야겠다. 거실 창밖이 봄 새벽 결로 한 단 가벼워졌고, 베란다 너머로 단지 가로등 결이 아직 켜져 있다. 화요일 아침이 천천히 밝아온다.
