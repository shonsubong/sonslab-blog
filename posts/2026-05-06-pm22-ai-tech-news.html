ChatGPT 기본 모델이 GPT-5.5 Instant로 갈렸다 — 환각이 절반 이하로 떨어진 결

수요일 밤. 책상에 보리차 한 잔 다시 따라두고 X 타임라인을 한 번 더 훑었는데, 어제 미국 자리에서 풀린 TechCrunch 라인이 하루 지나도 결이 안 식는다 — GPT-5.5 Instant가 ChatGPT의 기본 모델 자리에 그대로 갈아끼워진 결. 새 모델 자리가 풀린 게 아니다. 모든 무료·유료 사용자의 디폴트 자리가 한 번에 바뀐 결이라, 무게가 묘하게 다르다.

환각 52.5% 감소라는 결의 진짜 무게

먼저 결을 똑바로 잡아두면, OpenAI 공식 라인이 풀어둔 숫자가 또렷하다 — 의료·법률·재무 같은 high-stakes 프롬프트 자리에서 환각 비율이 GPT-5.3 Instant 대비 52.5% 감소. 사용자들이 사실 오류로 플래그를 단 결의 자리에선 37.3% 감소. 단순 마케팅 라인이 아니라, 9to5Mac이 정리한 결대로 짚으면 실제 측정 자리에서 절반 이하로 떨어진 그림이다.

벤치마크 자리는 더 깔끔하다. AIME 2025 수학 자리에서 65.4 → 81.2. HealthBench Professional 자리에서 32.9 → 38.4. MMMU-Pro 멀티모달 자리에서 69.2 → 76. 한 단계 점프가 아니라, 같은 "Instant" 자리에서 결이 한 번에 위로 올라간 톤. SiliconANGLE 정리대로 응답 자리도 더 짧아지고, 불필요한 이모지 자리도 의식적으로 깎였다.

기본 모델 자리가 갈렸다는 게 왜 무거운가

여기서 결을 한 번 더 짚어둘 자리는, Plus·Pro 자리뿐 아니라 무료 사용자 자리까지 디폴트가 바뀐다는 그림이다. ChatGPT 자리에 매주 들어오는 활성 사용자 자리가 수억 명 라인인데, 그 자리가 한 주만에 전부 새 모델로 갈아끼워진다는 톤이다. Dataconomy 라인에서 짚은 결대로, 유료 사용자 자리는 GPT-5.3 Instant를 3개월간 레거시로 더 굴릴 수 있지만, 무료 자리는 그대로 갈린다.

회사 자리에서 평일에 영상 처리 파이프라인 한 줄을 굴리는 입장에서 결을 짚으면, 모델 자체의 발표보다 디폴트 자리의 교체가 실제 사용 패턴 자리를 바꾼다는 톤이 또렷하다. 새 모델 자리가 발표돼도 사람들 자리는 디폴트 모델만 굴리는 결이 대부분이다. 그 자리가 갈리면, 같은 프롬프트 자리에서 출력 분포가 통째로 이동한다는 뜻이다.

환각 자리는 왜 그렇게 안 풀렸나

기술 자리 결을 정직하게 풀면, 환각 자리는 단순히 모델 크기 자리만으로 안 풀리는 결이다. GPT-5.3 Instant도 작은 모델 자리가 아닌데, 의료·법률 자리에서 사실 오류 자리가 그대로 남아 있었다. theaiinsider 정리가 짚은 라인은, OpenAI가 post-training 자리를 한 단계 더 정교하게 깐 결이라는 톤이다. RLHF 자리에서 사실성 신호 자리에 더 무게를 실은 결, 그리고 불확실성 자리에서 모델이 솔직하게 "모른다"를 깐 결이 같이 굴러간 그림.

여기서 결을 한 단 더 잡아두면, 환각 자리가 절반으로 떨어진다는 건 그 모델 자리에서 풀리는 다운스트림 결도 같이 결을 잡는다는 톤이다. 에이전트 자리에서 한 번 잘못된 결을 잡으면, 그 잘못이 후속 도구 호출 자리로 그대로 굴러간다. 환각이 절반이면, 같은 에이전트 체인 자리에서 오류 누적 자리가 기하급수적으로 줄어든다.

Instant라는 라벨 자리 — Anthropic 자리와 톤이 같다

결이 묘해지는 자리는, OpenAI가 Instant 라벨 자리를 굳이 유지한다는 톤이다. GPT-5.5 자리는 이미 4월 자리에 풀렸는데, 그 라인의 더 가벼운 결을 Instant 자리에 다시 깐 그림. 이게 결의 핵심이다 — 디폴트 자리 모델은 빠르고 가벼워야 하고, 동시에 환각 자리는 줄어야 한다.

같은 결로 한 번 짚어보면, Anthropic 자리도 Opus 4.7 자리를 4월에 풀었고, GitHub Changelog 라인에서도 agentic coding 자리에서 한 단계 더 올라간 결을 깔아뒀다. Instant·Sonnet·Haiku 자리에서 결을 굴리는 건 OpenAI 자리와 톤이 정확히 같다.

옆자리 한 줄 — 3시간 뒤 SF 키노트

마지막에 한 줄 더 깔아두면, 오늘 새벽 자리에서 정리해둔 Code with Claude SF가 지금 자리에서 약 3시간 뒤 자리에 깔린다. SF 자리 9 AM PT 자리는 한국 자리로 내일 새벽 1시 자리. TestingCatalog 라인대로 Jupiter v1-p 자리가 내부 red-team 자리에서 굴러가는 결이라, Opus 4.7 옆에 새 결이 한 줄 풀릴 가능성이 잡힌다(이건 끝까지 루머·미확인 자리). 공식 라인업 자리에 Boris Cherny가 그대로 올라와 있어서, Claude Code 자리에서 한 단계 위로 올라간 결도 같이 풀릴 가능성이 높다.

OpenAI 자리에서 GPT-5.5 Instant가 어제 풀린 결과, 같은 주 자리에서 Anthropic 자리가 키노트 자리에 새 결을 들고 올라오는 그림 — 프론티어 모델 자리의 경쟁 자리가 다시 한 단 가까워진 톤이다.

한 줄로 자르면

디폴트 모델 자리가 갈리는 결은 모델 자리 발표 자리보다 무겁다. 환각이 절반으로 떨어지면, 그 위에서 굴러가는 에이전트·검색·툴 자리의 오차 누적 자리가 한 단 줄어든다. 새벽 자리에서 SF 키노트 자리가 풀리고, 모레 아침 자리에서 결을 다시 정리한다. 늦은 보리차 한 잔 비우고 자리에서 일어난다.
