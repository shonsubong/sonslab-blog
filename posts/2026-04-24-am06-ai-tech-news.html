인텔 시간외 +16%, GPT-5.5는 가격 2배 — 밤사이 셋 정리

밤사이 미국장에서 세 개가 겹쳤다. 인텔이 시간외 +16%, OpenAI가 GPT-5.5를 가격 2배로 뿌렸고, TSLA는 정규장 -3.9%로 그냥 내려앉았다. 어제 새벽 포스트에서 제일 안 예상한 그림이 인텔 쪽이다. 하나씩 풀어본다.

인텔 Q1 — 컨센서스를 부숴버린 분기

어제 장 마감 직후 숫자가 나왔는데 모든 줄이 대형 서프라이즈였다.

  • EPS $0.29 vs 컨센 $0.01 (조정)
  • 매출 $13.58B vs 컨센 $12.36B
  • Intel Foundry $5.42B vs 컨센 $4.81B (+16% YoY)
  • Data Center & AI $5.1B vs 컨센 $4.41B
  • Client Computing $7.7B vs 컨센 $7.1B
  • Q2 가이던스 $13.8~14.8B vs 컨센 $13.03B

시간외에서 +16% 붙으면서 정규장 종가 $66.78에서 $76 근방으로 튀었다. 올해 YTD로 이미 +74% 올라온 종목이 어닝에서 한 번 더 점프한 구조라, "바닥 찍은 거 맞다"라는 내러티브가 숫자로 박혀버린 밤이다. (CNBC — Intel Q1 2026 earnings)

제일 중요한 한 줄은 파운드리다. Intel Foundry 매출 $5.42B, YoY +16%, 컨센 대비 $600M 이상 초과. 작년까지만 해도 "Intel Foundry는 분기마다 적자만 키우는 블랙홀"이었는데, 이번 분기엔 "적자 폭 축소 + 매출 초과 달성" 조합이 같이 나왔다. 거기에 2024년 Apollo에 $11.2B에 판 팹 지분 49%를 $14.2B에 되사오겠다는 발표가 붙었다. 3년 전 유동성 확보용으로 넘긴 자산을 30% 프리미엄 주고 회수하는 건데, 그만큼 자기들이 파운드리 턴어라운드에 확신이 섰다는 시그널로 읽힌다. (Stocktitan — Intel 8-K 공시)

이건 어제 SK하이닉스 콜에서 나온 "HBM 공급 부족 3년"과 별개로 봐야 한다. HBM은 메모리 축이고 파운드리는 로직 축이라 직접 경쟁 관계는 아닌데, TSMC 독점 구도에 균열이 생기는 시그널이라는 점에서 2026년 반도체 판 전체에 영향이 크다. 지난주 TSMC 분기 이익 +58% 서프라이즈 + 이번 주 Intel Foundry 턴어라운드 → 로직 파운드리 공급이 두 축으로 벌어지는 구도가 슬슬 보인다. 하이퍼스케일러 입장에선 협상력이 올라간다.

회사 안에서 보는 관점으로 얘기하면, TEM/SEM 검사 장비 쪽 공정 커스텀도 Intel 파운드리가 본격 가동되면 주문이 바뀐다. 지금은 TSMC 공정 레시피 맞춰 돌아가는 게 대부분인데, Intel 18A·14A 램프업이 실제 볼륨까지 오면 라인 하나를 따로 돌릴 수 있는 규모가 된다. 아직은 분기 실적만 좋은 거지 매스 프로덕션 리스크가 잡힌 건 아니라서, 이 포인트는 앞으로 2~3분기 더 봐야 확정이다.

GPT-5.5 — 가격 2배, 방향은 에이전트 쪽

같은 날 OpenAI가 GPT-5.5를 던졌다. Opus 4.7이 4월 16일에 나온 지 정확히 일주일 만. 시기가 시기다.

API 가격은 입력 $5 / 출력 $30 per 1M tokens. GPT-5.4 대비 2배. GPT-5.5 Pro는 입력 $30 / 출력 $180으로 Opus 4.7의 기본 티어($15/$75)보다 비싸다. 가격을 한 번에 2배 올리는 결정은 "이 모델은 이전 세대와 결이 다르다"고 강하게 찍어놓는 의미라, 컨퍼런스 콜 없이도 메시지는 선명하다. (TechCrunch — OpenAI GPT-5.5, Fortune — GPT-5.5 release)

벤치마크 분할이 흥미롭다.

  • 코딩 쪽 (SWE-bench Pro, SWE-bench Verified, CursorBench, GPQA Diamond): Opus 4.7이 우세. SWE-bench Pro에서 Opus 4.7 64.3% vs GPT-5.5 58.6%, 6.6pt 차이
  • 에이전트 쪽 (Terminal-Bench 2.0, GDPval, OSWorld, Tau2-bench): GPT-5.5가 우세. Terminal-Bench 2.0은 Anthropic의 Mythos Preview를 근소 차로 넘었다

(VentureBeat — GPT-5.5 Terminal-Bench 승리)

개발자 입장에서 이 분할이 의미하는 건 분명하다. 한 모델이 다 잡는 시대는 끝났다. 파일 리팩토링·버그 픽스·코드 퀄리티는 Claude Code + Opus 4.7로 돌리고, 다단계 툴 콜 엮는 에이전트 워크플로우는 GPT-5.5로 돌리는 2-모델 구성이 현실적인 선택이 된다. 가격을 2배 받으면서 coding에서 지는 모델을 내놓은 건 OpenAI가 의도적으로 축을 옮긴 거라고 본다.

어제 저녁 포스트에서 "Anthropic이 Claude Code 단독으로 연 환산 $25억"이라고 썼는데, GPT-5.5가 API $10/$60 수준(Pro 기준 $30/$180)으로 올라오면 OpenAI가 이 구간에서 Anthropic의 매출 성장을 얼마나 따라가느냐가 2분기 숫자의 핵심이 된다. 가격을 2배 받아도 볼륨이 비례해서 안 나오면 매출 증가율이 Anthropic에 또 밀린다.

내 개인 프로젝트(오픈소스 Rust 파서) 기준으로는 당분간 Opus 4.7 유지할 생각이다. Terminal-Bench에서 GPT-5.5가 이겼다고 하는데, 내 워크로드는 파일 편집·테스트 루프가 99%라 agentic shell 지표는 체감이 거의 없다.

TSLA 정규장 -3.9%, $372.46

개장 전 프리마켓 -2.87%에서 출발해서 결국 정규장 종가 $372.46, -3.9%. 어제 pm22 포스트에 "개장 30분이 흐름을 결정한다"고 썼는데, 실제로 개장 직후 30분 낙폭 잡지 못하고 저점 근방으로 마감했다. (Investing.com — TSLA 4/23 종가)

어제 새벽~저녁까지 네 개 포스트 쓰면서 이미 CapEx $25B·HW3 unsupervised FSD 불가·마이크로 팩토리 세 이슈는 다 풀어놨으니 여기선 반복 안 한다. 새로 추가된 건 없고, Gary Black이 언급했던 "2026 P/E 204배는 내려올 수밖에 없다" 라인을 시장이 한 번에 -3.9%로 받아낸 셈이다.

내 관심은 오늘(금요일) 장에서 반등이 나오는지 vs. 하루 더 밀리는지다. 어닝 다음날 -3.9%로 마감했으면 보통은 바닥 잡는 흐름이 따라오는데, HW3 소송 리스크가 사이드로 끼어있는 상태라 일반 공식 깨질 수도 있다. 주말 전 마지막 거래일이라 포지션 정리 수급도 붙는다.

오늘

아침 한국장 개장은 09시. 어제 SK하이닉스 보합·삼성 +3.22% 구도가 유지될지, 인텔 파운드리 턴어라운드 뉴스가 한국 반도체 소부장에 어떻게 반영될지가 오전 관전 포인트다. Intel 18A·14A 램프업은 한국 쪽 장비·소재 업체에도 발주 분산 기회다. 점심 포스트에서 한국장 오전 반응 보고 정리한다.
