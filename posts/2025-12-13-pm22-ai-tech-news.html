이 한 주, 정리하지 않으면 잊어버릴 것 같다

토요일 밤. 이번 주는 3일 간격으로 하나씩 터진 주라, 제대로 기록해두지 않으면 분기 리뷰 때 빠진 채로 지나간다. 세 이벤트로 정리.

12/10–11 — Microsoft AI Dev Days

MS가 Ignite 직후 연 Dev Days에서 가장 눈에 들어온 건 하드웨어·인프라 스택의 재정의였다. 앱 레이어 업데이트도 많았지만, 개인적으로는 아래가 더 무겁다.

Blackwell Ultra + 자체 실리콘

  • Nvidia Blackwell Ultra GPU + Cobalt(CPU) + Maia(AI 가속기) 조합을 프로덕션 레벨에서 공개.
  • 즉, MS는 "모든 게 Nvidia"가 아니고, 특정 워크로드는 자체 칩으로 내리겠다는 포지션을 명시.
  • 반도체 현직자로서 이 라인업이 체감되는 건, 커스텀 실리콘이 데이터센터 믹스에 실제로 들어왔다는 것. 예전엔 "Google TPU / AWS Trainium은 얘기만 크지 비중은 작다"가 정설이었는데, 이제 MS까지 합류. 엔드포인트 수요의 Nvidia 점유율이 점진 하향할 가능성이 커졌다.

Azure Boost DPU + Azure Integrated HSM

  • Boost DPU — MS 최초의 자체 DPU. 네트워크·스토리지 오프로드용. Pensando(AMD)/NVIDIA BlueField이 차지하던 자리에 자체 칩이 들어가기 시작.
  • Integrated HSM — 하드웨어 보안 모듈을 플랫폼에 내장. 엔터프라이즈 규제 대응 카드.

새 Azure Copilot — 라이프사이클 전체에 에이전트

마이그레이션·배포·관측·최적화·복원·트러블슈팅 각각의 전문 에이전트. "사람이 오케스트레이션하는 클라우드" → "에이전트 묶음이 자율 운영하는 클라우드"로의 이동. 이건 운영팀 헤드카운트에 바로 영향을 줄 이슈다.

12/11 — OpenAI GPT-5.2

예상대로 당겨 나왔다. 12월 11일부터 유료 플랜(Plus/Pro/Go/Business/Enterprise)에 롤아웃 시작.

세 모드 구성.

  • GPT-5.2 Instant — 대화·빠른 응답
  • GPT-5.2 Thinking — 표준·확장 사고 포함
  • GPT-5.2 Pro — 가장 깊은 추론

여기에 코딩 특화 GPT-5.2-Codex가 별도. 공식 포지셔닝은 "전문 지식 워크·장기 에이전트용 가장 진보한 프런티어 모델". 스프레드시트, 프레젠테이션, 코드, 이미지, 긴 컨텍스트, 도구 사용, 다단계 프로젝트 — 전반 상향 주장.

"Code Red"는 실재했다

이번 릴리스가 당초 12월 말에서 약 2주 당겨졌다는 해석이 많다. 11월 Gemini 3에 몇몇 카테고리에서 밀린 직후 OpenAI 내부에서 "Code Red" 비상 체제가 걸렸다는 보도가 있었는데, 타임라인을 보면 정합적이다.

벤치 수치

  • GDPval 70.9% (GPT-5.1의 38.8%에서 큰 폭 상승)

GDPval 한 개로 판단할 문제는 아니지만, 전문 지식 워크 카테고리에서 한 칸 위로 올라갔다는 건 분명한 신호. 당장 다음 주부터 실사용 리뷰가 쏟아질 것이다.

Nvidia Nemotron 3 Nano

3순위지만 따로 적을 만하다. Nemotron 3 패밀리가 공개됐고, 우선 가장 작은 Nano부터 풀렸다.

  • 더 빠르고, 더 싸고, 장기 멀티스텝 작업을 더 잘 한다
  • 대형 변형은 2026년 상반기 예정

Nvidia가 "칩만 파는 회사"에서 자체 모델 라인도 쥐는 회사로 이동하는 궤적. 엔비디아 입장에선 파운더리 → 플랫폼 → 모델까지 내려가는 그림이고, 반도체 업계 구조도가 서서히 바뀐다는 증거.

반도체 현직자가 읽는 한 주

세 이벤트를 엮으면 그림이 깔끔하다.

  • MS Dev Days — 자체 실리콘(Cobalt/Maia) 비중 확장 시도 → Nvidia 독점의 완만한 희석
  • GPT-5.2 — 더 긴 컨텍스트 + 더 복잡한 추론 → HBM3E·대역폭 수요 단기적 증폭
  • Nemotron 3 — Nvidia가 모델 레이어까지 → 수직 통합 심화

모순처럼 보이지만 동시성립한다. 단기 Nvidia 수요는 여전히 견조하고, 중장기 점유율은 희석 압력이 쌓인다. 이게 내가 2026년 상반기에 가장 유심히 볼 축이다.

다음 주 관전 포인트

  • GPT-5.2-Codex 실사용 벤치 (커뮤니티 리뷰)
  • Anthropic Dev Day 예정 이벤트 확인
  • 연준 12월 FOMC

한 달 전이었으면 "한 주에 이 세 개가 나온다고?" 싶었을 텐데, 지금은 그런 주가 매주 온다. 피로도는 쌓이지만 내 밥벌이 시장이 이렇게 움직이는 건 흥미롭다.

오늘은 여기서 끊는다. 내일은 간만에 산책이나.
