Claude Opus 4.6, 1M 토큰 컨텍스트 — PowerPoint·Excel 직접 통합

목요일 밤, Anthropic이 또 던졌다

퇴근하고 저녁 먹고 10시 넘어서야 오늘 발표 본격 정리. Anthropic이 저녁 시간대에 푸는 걸 좋아하는 것 같은데, 덕분에 업계 사람들이 밤마다 바쁘다.

오늘의 헤드라인 — Claude Opus 4.6 출시, 그리고 여기에 붙은 두 가지 서프라이즈.

발표 요약

  • Claude Opus 4.6 — 최상위 모델 버전업.
  • 1,000,000 토큰 컨텍스트 (beta) — 1M 창 공식 열림.
  • Microsoft PowerPoint / Excel 애드인으로 직접 배포 — Office 워크플로 안에서 Opus 4.6이 작동.
  • 코딩 성능 추가 향상 (구체 벤치는 내일 출시 노트 자세히 읽어야 함).

"1M 컨텍스트"가 의미하는 것

1M 토큰은 대략 75만~80만 단어 규모다. 예를 들자면.

  • 영어 소설 약 8~10권
  • 중형 기업 분기 실적 자료 + 10K + 재무 모델 통째로
  • 반도체 공정 레시피 + TEM 이미지 메타데이터 + QA 로그 한 주 분량

이 마지막 카테고리가 내 업무 범위. 그동안 Claude에 레시피 몇 개 넣고 질문하면, 컨텍스트 초과로 중간에 잘리거나 retrieval을 엮어야 했다. 이제는 "그냥 한 방에 넣고 질문"이 가능해진다. 이게 내 분기 생산성 체감에 직접 영향을 준다.

MS Office 직접 통합

진짜 큰 뉴스는 오히려 PowerPoint/Excel 애드인 배포다.

  • PPT 안에서 슬라이드 직접 생성·수정·리뷰
  • Excel 안에서 수식·데이터 분석·시각화 제안

이게 뭘 말하는가. Anthropic이 Microsoft 365의 기본 인터페이스로 들어갔다는 것. Copilot과 직접 경쟁하는 자리에, Anthropic 모델이 병렬 선택지로 올라갔다는 의미.

이걸 MS가 허락했다는 점이 흥미롭다. 12월 Anthropic-MS 컴퓨트 딜 ($15B 투자 / $30B 컴퓨트)과 엮어 읽으면 그림이 풀린다. MS는 자사 워크플로를 플랫폼화하고 있고, 그 위에서 Anthropic·OpenAI 모델이 복수 옵션으로 돈다. 과거엔 Copilot이 곧 GPT였지만, 이제는 Copilot이 멀티모델 라우터가 되는 거다.

반도체 현직자 각도

1) 1M 컨텍스트 = 메모리·대역폭 수요 폭증

컨텍스트가 4배 늘면 추론 시 KV cache가 4배 커진다. 이걸 낮은 레이턴시로 서빙하려면 HBM 대역폭과 캐퍼시티가 더 필요. SK하이닉스·삼성 HBM4 스토리에 1M 컨텍스트 도입은 또 하나의 펌프.

2) 엔터프라이즈 온디바이스 압력

1M 토큰 + 민감 데이터(사내 문서) 조합은 "클라우드 유출 없이 처리" 요구를 자극한다. Apple Silicon 클러스터 (12월 TB5 RDMA 포스트에서 다룬) 같은 로컬 솔루션이 엔터프라이즈 구매 대상이 될 가능성이 점점 높아짐.

3) Nvidia 수혜

분명한 건 단기 추론 수요 폭증 → Nvidia·Broadcom 직접 수혜. Capex 증가 스토리가 유지될 근거 추가.

주변 뉴스 간단 메모

  • Grok Imagine 1.0 (2/2) — xAI의 텍스트→이미지 모델. 벤치는 이미 구글 Imagen·OpenAI 이미지 급 중급.
  • 중국 춘절 연휴 본격 시작 — 다음 주 아시아 거래량 감소. 시장 방향성 불분명 구간.
