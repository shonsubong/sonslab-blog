Gemini 3.5 Flash 벤치 숫자가 나왔다 — 구글이 3.5 Pro를 미루고 Flash를 먼저 푼 이유

새벽 키노트는 자느라 결만 받아두고 출근했는데, 오전 사이에 Gemini 3.5 Flash 벤치 숫자가 공식으로 풀렸다. 새벽 글에서 "점심까지는 agentic coding 벤치 숫자가 박힐 것"이라고 적어뒀는데, 진짜로 그 시간표대로 나왔다. 점심에 핸드폰으로 한 번 정리해둔다.

숫자부터 — Flash가 한 세대 위인 3.1 Pro를 코딩·에이전트에서 앞섰다

구글이 공개한 자체 수치 기준이다. Terminal-Bench 2.1 76.2점 (Gemini 3.1 Pro는 70.3점), MCP Atlas 83.6점 (78.2점), Finance Agent v2 57.9점 (43.0점), GDPval-AA 1656 Elo (1314). DataCamp 정리·llm-stats 정리가 같은 표를 받았다.

핵심은 이거 하나다 — 경량 모델인 Flash가 한 세대 위인 Pro를 코딩·에이전트 벤치에서 앞섰다. 거기에 output tokens/sec가 다른 프론티어 모델보다 4배 빠르다는 게 구글 주장이다(Interesting Engineering). 에이전트는 같은 작업을 수십 번씩 반복 호출하니까, 모델 지능만큼이나 단가와 속도가 곧 성능이다. 그 자리를 노린 모델이라는 게 또렷하다.

다만 "GPT-5.5를 agentic 벤치에서 앞섰다"는 Seeking Alpha 헤드라인은 한 단 걸러서 봐야 한다. 구글 발표 기준이고 독립 검증은 아직이다. 어제 밤 글에서 짚어둔 Terminal-Bench 2.0의 GPT-5.5 82.7점 vs Composer 2.5 69.3점과 이번 Terminal-Bench 2.1의 Flash 76.2점을 곧바로 한 줄에 놓고 비교하면 안 된다 — 벤치 버전(2.0 vs 2.1)이 다르다. 교차검증 숫자는 며칠 더 굴러봐야 톤이 잡힌다.

3.5 Pro는 미뤘다 — 챗봇이 아니라 에이전트에 거는 신호

이번 I/O에서 흥미로운 건, 구글이 3.5 Pro를 미루고 Flash를 먼저 냈다는 점이다(Let's Data Science). TechCrunch는 이걸 "다음 물결을 챗봇이 아니라 에이전트에 건다"고 읽었다. 가장 똑똑한 한 방을 자랑하는 게 아니라, 근(near)-Pro 품질을 Flash 단가·속도로 굴리는 모델을 메인에 올린 셈이다. 에이전트 시대에는 이게 더 무거운 카드라는 판단이다.

엔지니어 입장에서 실무로 와닿는 한 줄은 따로 있다 — Gemini 3.5 Flash가 GitHub Copilot에 바로 GA로 깔렸다(GitHub Changelog). near-Pro 코딩 품질에 cache efficiency가 좋고 tool use가 강해서, 빠르게 반복하는 agentic coding에 맞는다는 설명. 회사에서는 보안 정책상 Claude Code도 외부 에이전트 도구도 못 쓰니까 직접 못 돌려보지만, 집에 와서 개인 프로젝트에 한 번 물려볼 만한 후보다. 도입 사례도 같이 풀렸는데 Shopify가 subagent를 병렬로 굴려 판매자 성장 예측을 돌리고, Salesforce는 Agentforce에 넣고, Xero는 몇 주짜리 멀티위크 워크플로우에 붙였다(WinBuzzer).

같은 날, Code with Claude가 런던에 도착했다

타이밍이 묘하다. 오늘부터 내일(5/20~21) Code with Claude가 런던에서 열린다(Every 리뷰). 5월 6일 샌프란시스코 본행사에서 Dario Amodei가 1분기 매출이 연환산 80배 성장(계획은 10배였다)이라고 말했고, managed agents·proactive workflows 같은 에이전트 쪽 결을 공개한 바로 그 컨퍼런스의 유럽 일정이다(InfoQ).

새벽 글에서 MCP가 프론티어 세 곳(Anthropic·Google·OpenAI)에서 같은 표준으로 박혔다고 정리해뒀는데, 그 위에서 에이전트 도구 자리의 경쟁이 가격으로 옮겨붙는 톤이 같이 보인다. Axios 라인대로, Anthropic은 외부 에이전트 도구를 유료 플랜에 다시 허용하되 별도 크레딧 미터를 붙였고, Sam Altman은 X에서 신규 비즈니스 고객에게 Codex 2개월 무료로 맞불을 놨다. 표준은 합쳐졌으니 이제 누가 더 싸게·많이 굴리게 해주냐가 다음 싸움이라는 그림이다. 개인 사용자 입장에선 단가가 내려가는 방향이라 나쁠 게 없다.

오늘 점심의 한 줄만 추리면 — 구글이 제일 똑똑한 모델이 아니라 제일 잘 굴러가는 에이전트용 모델을 메인에 올렸다는 게 봄 끝자락의 신호다. 오후 흐름 보고 저녁에 한 번 더 정리하면 되겠다. 점심 끝.
