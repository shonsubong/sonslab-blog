이번 공급망 공격은 Claude Code 키까지 노렸다 — VS Code 확장 하나가 11분 만에 한 일

일요일 새벽인데 또 일찍 깼다. 원래는 커피 내리고 개인 PC에서 주말 토이 프로젝트나 마저 만지려고 했는데, 노트북 열자마자 제일 먼저 한 건 코딩이 아니라 ~/.claude/settings.json 열어보는 거였다. 이번 주 내내 머릿속을 떠나지 않던 뉴스 때문이다. 내 개인 장비에 깔린 Claude Code 설정 파일이, 이번 공격의 정확한 표적이었거든.

가짜 확장 하나, 11분, 그리고 하필 그 파일

사건 자체는 단순하다. 5월 18일, Nx Console이라는 VS Code 확장의 가짜 버전(v18.95.0)이 마켓플레이스에 올라왔다. Nx 공식 권고 기준으로 마켓플레이스에 살아있던 시간은 약 11분. 그 짧은 사이에 누가 깔았느냐가 문제였다.

이 가짜 확장은 설치되자마자 조용히 자격증명 탈취 스크립트를 돌렸다. 노린 건 GitHub 토큰, npm 토큰, AWS 키, 1Password 볼트 — 그리고 거기에 ~/.claude/settings.json이 끼어 있었다. The Hacker News와 Help Net Security 보도를 보면, 보안 업계가 "AI 코딩 도구의 자격증명·설정을 노린 사실상 첫 공급망 페이로드"라고 부르는 이유가 이거다. 그냥 소스코드를 긁어가려던 게 아니라, 에이전트 도구의 열쇠를 통째로 가져가려 했다는 점.

배후는 TeamPCP(UNC6780으로도 추적되는)라는 금전 목적 그룹이고, 이렇게 턴 GitHub 자격증명으로 CI/CD 파이프라인을 타고 들어가 GitHub 내부 저장소 약 3,800개를 빼냈다고 GitHub이 5월 19일 공식 확인했다. 피해는 GitHub만이 아니다 — OpenAI(직원 단말 2대), Mistral(소스 유출 빌미로 협박), 유럽연합 집행위원회 사이트까지 같은 캠페인에 엮였다. Nx CEO Jeff Cross는 실제 설치 수가 마이크로소프트 초기 집계(28건)보다 훨씬 많은 6,000건을 넘을 수 있다고 했다.

엔지니어로서 진짜 서늘했던 포인트는 따로 있다. 전통적인 엔드포인트 보안은 컴파일된 실행파일의 시그니처를 본다. 그런데 VS Code 확장, npm 패키지, PyPI 배포물은 죄다 평문으로 된, 해석되어 그냥 돌아가는 물건이다. 개발자가 매일 별 의심 없이 install 누르는 그 레이어. 방어 도구가 보는 층이랑 공격이 들어오는 층이 아예 다르다는 거다. 그래서 11분이면 충분했다.

내가 이걸 남 일로 못 넘긴 건, 이게 딱 내 셋업이라서다. 나는 회사에선 Claude Code를 못 쓴다(보안 정책). 그래서 Claude Code는 전부 개인 PC랑 개인 폰에서만 굴린다. 즉 이번에 털린 그 ~/.claude/settings.json이 바로 내 집 노트북에 있는 그 파일이라는 얘기. Anthropic API 키 하나 빠져나가면 그건 단순 코드 열람이 아니라 내 명의로 에이전트를 돌릴 수 있는 권한이 넘어가는 거다. 그래서 어제 토요일은 토이 프로젝트는 제쳐두고 개인 키부터 갈았다. 권고대로 Anthropic API 키 재발급, settings.json에 박아둔 MCP 서버 자격증명 전부 교체, 그 MCP 서버들 활동 로그 점검. 주말 내내 X 보안 계정 타임라인도 "묻지도 따지지도 말고 키부터 갈아라"로 도배돼 있었다.

같은 토큰을, 누구는 귀엽게 읽는다 — tokenmaxxing과 Clawdmeter

묘한 건, 바로 같은 주에 정반대 결의 뉴스가 하나 더 돌았다는 거다. 아이슬란드 레이캬비크의 개발자 Hermann Haraldsson이 만든 Clawdmeter라는 오픈소스 가젯. 손바닥만 한 데스크탑 장치인데, Claude Code 사용량이 올라갈수록 픽셀아트 애니메이션이 점점 분주해지고, 세션·주간 사용률 차트를 보여준다. 5월 10일 공개했는데 벌써 GitHub 스타 800개 넘고 포크도 50개 달렸단다. 본인은 임베디드 개발자도 아닌데 "Claude가 며칠 만에 다 알려줬다"고. 그러니까 Claude로 만든, Claude 사용량 보는 기계인 셈이다.

이게 요즘 개발판에서 번지는 "tokenmaxxing" 흐름의 상징처럼 됐다. AI를 얼마나 잘 쓰고 있냐를 토큰을 얼마나 태웠냐로 자랑하는 분위기. 월 $200 MAX 쓰는 입장에서 솔직히 그 농담 안다 — 사용량 그래프 우상향하면 괜히 뿌듯하지.

근데 어제 키 갈면서 깨달은 게 있다. Clawdmeter가 사용량을 어떻게 읽느냐면, Claude Code OAuth 토큰을 읽어서 API를 한 번 호출하고 응답 헤더에서 숫자를 빼온다. 위에서 말한 그 악성 확장이 노린 것도 결국 같은 토큰, 같은 설정 파일이다. 한쪽은 그 열쇠로 귀여운 픽셀 미터를 그려주고, 다른 한쪽은 그 열쇠로 네 저장소를 복제해 간다. 차이는 기술이 아니라 의도뿐이다. 에이전트 시대가 모든 개발자 디스크에 꽤 센 열쇠를 하나씩 박아놨는데, 그걸 뭐가 읽고 있는지는 정작 우리가 잘 안 본다는 거.

이번 주의 진짜 자랑거리는 토큰을 얼마나 태웠냐가 아니라, 네 토큰이 아직 네 것이냐일지도 모르겠다. 커피 마저 내리고, 키 교체 끝낸 김에 settings.json 한 번 더 훑고 나서야 토이 프로젝트로 돌아갈 수 있겠다. 일요일 아침치고 시작이 좀 빡세네.
