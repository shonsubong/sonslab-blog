DeepSeek V4가 또 판을 흔들었다 — V4-Pro·V4-Flash 동시 공개

새벽 포스트에서 X-energy IPO 얘기 했는데, 점심쯤 다시 보니 어제 밤사이 더 큰 사건이 같이 터졌었다. DeepSeek V4 프리뷰다. 미국 시간 4/24 금요일에 V4-Pro·V4-Flash 두 모델 동시 공개. 작년 1월 V3 "스푸트니크 모먼트" 이후 정확히 1년 만이다. 새벽엔 살짝 흘려봤는데 점심에 자료 좀 더 보다 보니 이건 한 포스트 따로 빼는 게 맞다.

스펙 한 줄 정리

  • V4-Pro: 1.6T 총 파라미터, 활성 49B (MoE), 1M 토큰 컨텍스트
  • V4-Flash: 284B 총 파라미터, 활성 13B (MoE), 1M 토큰 컨텍스트
  • 새 구조 Hybrid Attention Architecture 도입 — 긴 컨텍스트에서 KV 캐시·FLOPs 대폭 감축
  • 가격: Pro 입력 $1.74 / 출력 $3.48 (백만 토큰), Flash 입력 $0.14 / 출력 $0.28
  • chat.deepseek.com Expert/Instant 모드 + API 동시 오픈

V4-Pro는 현존 오픈 웨이트 최대 모델이다. Kimi K2.6(1.1T), GLM-5.1(754B)을 뛰어넘었고 V3.2(685B)의 2배 이상. (Simon Willison — DeepSeek V4, almost on the frontier, DeepSeek API Docs — V4 Preview Release)

진짜 의미 — 가격이다

벤치마크부터 보면. SWE-bench Verified에서 V4-Pro 80.6점. Claude Opus 4.6이 80.8, Gemini 3.1-Pro가 80.6. 즉 코딩 실전 벤치는 프론티어와 0.2점 차이다. 수학·세계지식은 Gemini 3.1-Pro에만 살짝 밀리고, GPT-5.4·5.5와는 3~6개월 정도 뒤처진 트랙으로 본다는 게 시장 평가. (VentureBeat — V4 at 1/6th the cost of Opus 4.7, GPT-5.5, TechCrunch — DeepSeek closes the gap)

근데 가격 차이가 미쳤다. Claude Opus 4.6이 출력 백만 토큰당 $25, GPT-5.4가 $15. V4-Pro는 $3.48. 같은 워크로드를 V4-Flash로 돌리면 Opus 대비 89배 싸다(Willison 계산 기준).

성능은 0.2점 차이, 가격은 7~89배 차이. 이게 뭘 의미하냐면, 기업·개발자가 "프리미엄 미국 모델 = 디폴트"였던 의사결정을 다시 한다는 거다. 특히 에이전트형 워크로드처럼 토큰을 대량으로 태우는 곳에서 격차가 극심해진다.

Huawei Ascend로 학습했다 — 이게 더 큰 그림

기술적인 부분만큼이나 무거운 게 인프라 쪽이다. Huawei가 어제 공식 확인했다 — DeepSeek V4는 Huawei Ascend 950PR 칩으로 학습했다. Nvidia 하드웨어가 아니다. (CNBC — DeepSeek V4 + Huawei chips, Fortune — V4 + Huawei Ascend integration)

작년 V3는 H800 기반이었고, 미국 수출 통제 영향 안에서 어떻게든 우회한 그림이었다. 1년 만에 학습 인프라까지 자체 공급망으로 갈아탔다는 뜻이다. Ascend 950PR은 작년 9월 공개된 신형이고, V4 학습이 이걸로 끝났다는 건 양산·소프트웨어 스택이 실제 프로덕션 학습 워크로드를 받아낸다는 첫 공개 검증이다.

Nvidia 투자자 관점에서 이걸 어떻게 봐야 하나. 단기 수요엔 변화 없다. 미국 빅테크 4/29 어닝에서 CapEx 가이던스가 더 위로 갈 가능성이 여전히 크다. 다만 5~10년짜리 TAM 시나리오에서 "중국 AI 인프라는 Nvidia 매출에서 점진적으로 빠지는 라인"으로 잡고 가야 한다. 작년만 해도 "결국 우회 수입으로 들어온다"는 시각이 컸는데, 어제 발표는 그 가정 자체를 흔든다.

TSMC·HBM 공급망 입장에선 또 결이 다르다. Ascend 950PR도 어차피 첨단 노드가 필요하고, HBM은 삼성·SK하이닉스 의존. 즉 "Nvidia를 통하지 않는 중국 AI"가 늘어나도, HBM 수요 총량은 오히려 더 늘어나는 그림에 가깝다. 어제 SOX 18일 연속 상승이 이걸 미리 반영했다는 해석도 가능하다.

회사 관점 vs 집 관점

집에서 개인 PC로 Claude Code Max $200 쓰고 있는 입장에서, V4-Pro API를 당장 갈아탈까? 솔직히 안 갈아탄다. Claude Code의 강점은 모델 자체보다 에이전트 루프·도구 사용·컨텍스트 관리가 워크플로우에 묶여 있다는 점이고, $200 정액 안에서 토큰 신경 안 쓰고 돌릴 수 있다는 게 본질이다. V4-Flash가 출력 $0.28/M로 미친 가격이긴 한데, API 직접 호출 워크플로우를 다시 짜야 본전이 나온다.

다만 OpenRouter 같은 라우팅 레이어로 엮어서 체인지·플래그해두는 건 의미가 있다. 큰 일감(긴 코드베이스 분석)은 V4-Pro로, 빠른 잡일은 V4-Flash로, 정밀한 리팩토링은 Claude Opus로 — 이 분기 짜는 사람들이 다음 주에 많이 나올 거다.

회사 안에서는 또 다른 얘기다. 사내 Claude Code 못 쓴다는 건 여러 번 짚었고, 외부 API 호출 자체가 막혀있다. V4 같은 오픈 웨이트 모델은 사내 GPU 클러스터에 자체 호스팅 시나리오로 평가가 들어갈 가능성이 있다. 1.6T MoE 풀 호스팅은 비현실적이지만, 284B Flash라면 검토 후보가 된다. 다음 주 출근하면 인프라 팀에서 한 번 회의 잡힐 분위기.

점심 한 줄

벤치마크는 거의 따라붙었고 가격은 1/10, 학습 인프라는 자체 공급망. 이 셋이 하나의 발표에 묶여 나온 게 어제다. 4/29 빅테크 어닝 콜에서 CFO·CEO들이 "DeepSeek"이라는 단어를 어떻게 다루는지가 다음 주 첫 관전 포인트다.
