Anthropic이 OpenAI를 처음으로 넘었다 — $900B 라운드 위에 Claude Code 런레이트가 깔렸다

점심. 어제 콜이 다 닫히고 "Anthropic이 결국 OpenAI 위로 한 번 점프하는구나" 라는 X 스레드가 어젯밤부터 계속 돌고 있다. Bloomberg가 먼저 던지고 TechCrunch가 받은 라인 — $50B 신규 라운드, $850B~$900B 밸류. 정확히 두 달 반 전 2월 라운드가 $380B였으니까 2.4배가 한 분기 안에 다시 그어졌다. 결의 결을 잡는 자리는 밸류 자체가 아니라, 그 밸류를 깔아주는 런레이트 라인이다.

$30B → $40B — 런레이트가 한 분기를 통째로 점프했다

3월 시점에 공개된 Anthropic의 연환산 매출은 $30B였다. 한 달 반이 지난 지금 $40B에 더 가깝다 는 라인이 TechCrunch 소스에서 풀렸다. 작년 말 $9B에서 시작했던 회사가 4개월 만에 4.4배 를 찍었다는 건데, 이 결을 enterprise tier 갱신 정도로 설명하기엔 폭이 너무 크다. 결을 만드는 자리는 한 군데로 좁혀진다 — Claude Code.

SaaStr 정리에 따르면 Claude Code 단독 ARR이 $2.5B(2월) → $14B 라인(4월) 으로 한 분기에 5배 점프했다. 이쯤 되면 코딩 AI 가 별도 카테고리가 아니라 Anthropic 전체의 첫 번째 사업부가 된 결이다. "Claude는 chatbot 회사가 아니라 dev tool 회사다" 라는 X 스레드 톤이 이제 농담이 아닌 자리로 깔렸다.

엔지니어 자리에서 결을 한 번 더 잡아주는 건 enterprise seat 단가가 일반 ChatGPT Plus 라인보다 한 자릿수 위 라는 점이다. Claude Code MAX 구독을 1년 가까이 굴려보면 코드베이스 전체를 컨텍스트로 던져도 안 흔들리는 경험이 매달 한 단계씩 깊어진다. 이게 "개발자 1인당 ARPU가 다른 LLM 제품 대비 5~10배" 라는 라인의 실체다. 회사 자리에서야 보안 정책 때문에 못 굴리지만, 개인 프로젝트로 굴려본 톤만 보면 "왜 dev tool 카테고리에서 OpenAI가 밀리는가" 가 손에 잡힌다.

$725B 인프라 위에 깔린 그림 — Google이 라운드를 노리는 이유

같은 주에 풀린 Q1 capex 발표도 이 맥락에서 같이 읽혀야 한다. 4월 29일 콜에서 알파벳·MS·메타·아마존이 일제히 2026 가이던스를 끌어올리면서 합산 $725B 라인이 굳었다. 작년 $410B 대비 +77%다. 이 자본이 향하는 자리는 결국 프론티어 모델을 굴릴 수 있는 회사 두 군데, OpenAI와 Anthropic이다. TechCrunch가 4월 24일 정리한 그림대로 Google이 Anthropic에 cash + compute로 $40B을 추가로 박는다 는 라인이 이번 라운드 직전에 풀렸다. Google Cloud의 TPU 캐파를 Claude 트레이닝/추론에 깔아주는 대가로 지분을 한 번 더 깊이 가져가는 그림이다.

여기서 결이 묘해지는 자리가 있다. 알파벳은 자기네 Gemini를 굴리고 있다. 왜 Anthropic에 자본을 또 꽂는가. X에서 한 분석가가 짚은 라인이 깔끔했다 — "Google은 모델 한 개로 세상을 다 먹을 수 없다는 걸 가장 먼저 인정한 hyperscaler". Apple이 어제 Gemini-Siri 라우팅을 티어드 시스템으로 깔았던 결정과 같은 자리에서 같은 답을 적은 셈이다. "한 모델이 모든 자리를 다 못 잡는다" — 어제 새벽 적어둔 그 라인이 점심 자리에서 한 번 더 굳었다.

OpenAI는 어떻게 받아치고 있나

같은 주에 OpenAI도 연환산 $25B 라인을 넘었고 IPO를 준비한다는 라인이 풀렸다. 지난 새벽 GPT-5.5-Cyber를 Trusted Access 라인으로 푼 게 이 결을 만드는 한 조각이다 — general 모델 한 줄로 다 잡지 않고, 도메인별 specialist 모델로 정부·금융·인프라 자리를 따로 묶는 그림. Anthropic이 Claude Code = 개발자 자리 를 잡았다면, OpenAI는 GPT-5.5-Cyber = 보안 자리, 그리고 곧 풀릴 헬스케어 specialist 라인으로 나눠 잡는 결이다.

엔지니어 자리에서 결을 잡으면, frontier general model 하나로 모든 도메인을 다 먹는 시즌은 작년까지였고, 이제는 도메인 specialist 모델 + 도메인별 enterprise 라인 이 2026 후반의 결이 된다. Anthropic의 Claude Code 라인이 그 첫 번째 답안이고, OpenAI의 Cyber/Trusted Access가 두 번째 답안이다. 프론티어 한 줄에서 도메인 여러 줄로 — 이 분기점이 한 번 그어진 자리.

점심 끝나기 전 한 줄

$900B는 숫자보다도 카테고리 하나가 분기 안에 다시 정의됐다 는 사실이 결을 잡는 자리다. 작년 이맘때만 해도 코딩 AI는 Copilot의 카테고리 였다. 1년 만에 Claude Code의 카테고리 로 통째로 넘어왔다. 이 속도가 2026년 안에 한 번 더 같은 일을 겪을 카테고리가 무엇인지 — 점심 다 먹고 콜 정리하면서 그 자리부터 다시 봐야겠다.
