xAI가 코딩 에이전트 자리에 끼어들었다 — Grok Build, 세 갈래로 갈라진 봄의 결

일요일 새벽이다. 어제 밤에 Gemini Omni 누출 자리를 짚어두고 거실 불을 끄러 가다가, 마지막에 X 타임라인 한 번 더 굴려봤는데 그 자리에 한 줄이 박혀 있었다 — xAI가 Grok Build를 풀었다. 미국 시간 5월 14일 자리. 어제 새벽엔 OpenAI Codex 폰 결을 짚어두고, 점심엔 Nemotron Nano Omni를, 오후엔 Runway 세계모델을, 밤엔 Gemini Omni를 짚어둔 한 주의 끝자락에서, 코딩 에이전트 자리가 통째로 세 갈래로 갈라진 결이 또렷해진 자리.

Grok Build — "Arena Mode와 plan mode를 같이 들고 들어왔다"

Engadget 라인과 DevOps.com 라인, Dataconomy 라인을 묶어두면 결의 핵심이 한 줄로 정리된다 — Grok Build는 CLI 자리에 박힌 에이전트다. Claude Code랑 결의 모양 자체가 닮았다. 다만 xAI가 한 단 더 박은 자리가 두 개 있다.

첫째 — Arena Mode. 같은 문제를 여러 서브 에이전트한테 동시에 던지고, 그 결과들을 자기들끼리 경쟁시켜 랭킹을 매긴 뒤, 개발자한테는 상위 결만 올라온다. techloy 라인이 정리한 톤에선 최대 8개 서브 에이전트가 동시에 굴러간다. Claude Code의 sub-agent 결이 역할 분담 쪽이라면, Grok Build의 결은 경쟁 토너먼트 쪽이다. 결의 무게가 다른 자리에 박힌다.

둘째 — plan mode. 코드를 건드리기 전에 파일 단위·스텝 단위로 계획을 먼저 적어내고, 사용자가 그 자리에 코멘트를 박거나 통째로 다시 쓸 수 있다. 어제 새벽에 짚어둔 Codex 폰 자리의 approval gate랑 같은 결인데, 데스크탑 자리에 박힌 톤이다. 사람이 한 단 위에서 결을 잡고 들어간다는 자리.

셋째로 한 단 묵직한 결 — local-first·air-gap 호환. Kingy AI 라인이 짚은 톤에선 코드가 xAI 서버로 흘러가지 않는다. 초기 설정만 끝나면 오프라인 환경에서도 굴러간다. 회사 자리 — 보안 정책상 코드 외부 반출이 안 되는 자리 — 에선 이 결이 묵직하다. Claude Code도 비슷한 결이긴 한데, air-gap 호환을 공식적으로 박은 톤은 한 단 더 또렷한 라인이다.

벤치마크 — 70.8% 자리, Claude Opus 4.7과의 결의 거리

숫자 자리를 정직하게 짚어두면 — Grok Build를 굴리는 grok-code-fast-1 모델이 SWE-Bench Verified에서 70.8%. 컨텍스트 윈도우 256K. basenor 라인이 정리한 톤이다. 같은 벤치마크 자리에서 Claude Opus 4.7이 87.6%, SWE-bench Pro에서 64.3%. 결의 거리가 또렷한 자리.

다만 벤치마크 한 줄로 결을 다 가르긴 어렵다. xAI 자리에서 한 단 더 박은 결은 속도와 가격이다. grok-code-fast-1이라는 이름 자체가 그걸 박아둔 톤 — Opus 4.7 자리의 무게가 아니라, Sonnet/Haiku 자리의 가벼움을 노린 결. 그리고 SuperGrok Heavy 구독 자리에 묶었는데, 평소 $299/월 자리를 6개월 한정 $99/월 프로모션으로 풀었다. Claude Code의 $200/월 Max 자리와 정확히 비슷한 가격대다.

엔지니어 입장에서 한 단 짚어두면 — Grok Build를 Claude Code의 대체로 굴리진 않을 것 같다. 코딩 결의 신뢰가 아직은 Claude Opus 4.7 쪽이 한 단 묵직하다. 다만 Arena Mode 결은 굴려볼 자리가 있다. 같은 문제를 8개 에이전트한테 던지고 결과를 경쟁시키는 결은, 오픈소스 프로젝트 자리에서 한 번씩 굴려볼 만한 결이긴 하다. 회사 자리 코드는 어차피 못 쓰고(보안 정책), 개인 핸드폰·집 PC 자리 사이드 프로젝트 결에선 Claude Code Max 자리 옆에 Grok Build를 한 번 깔아두고 같은 문제를 양쪽에 던져보는 결도 한 번 굴려볼 만하다.

코딩 에이전트 자리가 세 갈래로 갈라진 봄

한 주를 묶어두면 결의 그림이 또렷하다.

Anthropic 자리 — 6월 15일부터 Agent SDK·claude -p 자리를 별도 크레딧 풀로 떼어내는 결. 컨트롤 서피스는 그대로 두고 과금의 결만 갈랐다. 제품의 결을 다듬는 자리.

OpenAI 자리 — Codex를 폰으로 옮긴 결. 코드는 여전히 데스크탑·원격 머신에서 굴러가고, 폰은 원격 뷰어 + approval gate 자리로 올라왔다. 컨트롤 서피스의 결을 옮긴 자리.

xAI 자리 — Grok Build를 CLI로 풀고 Arena Mode·plan mode·local-first 라인으로 처음부터 들어왔다. 제품의 결을 처음부터 다르게 그린 자리.

같은 시장 자리에 셋이 다 들어와 있긴 한데, 결의 방향이 정확히 다른 곳을 노린다. Anthropic은 기존 사용자 자리를 다듬고, OpenAI는 사용자가 책상에서 빠져나오는 결을 노리고, xAI는 처음부터 다른 결로 끼어들었다. 봄 한가운데서 코딩 에이전트가 한 카테고리로 정착된 게 아니라, 결이 갈라지면서 다양해지는 그림이다.

사이드 자리 — Gemini 3.2 Flash, I/O 이틀 전 결의 톤

같은 새벽에 묶어둘 결 하나 더. AIxploria가 정리한 라인대로 Gemini 3.2 Flash가 iOS 앱과 AI Studio 자리에 잠깐 떴다. 흥미로운 결은 벤치마크 자리에서다. LM Arena 자리의 초기 결에서 Gemini 3.1 Pro를 코딩 자리에서 이긴 톤. 특히 ASCII 애니메이션·SVG 생성·3D 인터랙티브 코딩 자리에서 3.1 Pro가 깨진 코드를 뱉을 때, 3.2 Flash는 2분 안에 굴러가는 결을 떨궜다는 라인.

가격 자리도 묵직하다 — input $0.25 / output $2.00 per 1M tokens. Gemini 3 Flash($0.50/$3.00) 대비 입력 절반, 출력 33% 인하. piunikaweb 라인에 박힌 결대로 Liquid Glass라는 새 UI도 같이 떴다.

어제 밤에 짚어둔 Gemini Omni 결과 묶어두면 — Google이 이틀 뒤 키노트 자리에서 Flash 라인·Omni 라인·Spark 라인을 동시에 깐다는 그림이 한 단 또렷해진다. 결의 톤이 모델 한 줄·UI 한 줄·에이전트 한 줄로 세 갈래. 한국시간 수요일 새벽 2시 키노트 자리가 봄의 결을 한 단 다시 그리는 자리가 될 자리다.

묶어두면

일요일 새벽 한 줄로 정리하면 — 코딩 에이전트 자리가 봄 한 주 사이에 세 갈래로 갈라졌고, Google이 이틀 뒤 키노트 자리에서 모델 라인을 통째로 받아칠 그림이 깔렸다. xAI는 Arena Mode·local-first로 결을 다르게 그렸고, Anthropic은 과금 결, OpenAI는 컨트롤 서피스 결. 다음 한 주는 이 세 결이 각자 어떤 사용자 결을 받아내는지가 톤을 가르는 자리.

Tesla 자리에서 한 줄 묶어두면 — FSD v14 자리의 결도 같은 라인 위에 박혀 있다. 같은 시간 자리에 세 회사가 자율 에이전트를 푸는 결과 Tesla가 7년 동안 굴려온 자율주행 결은 본질이 같은 그림이다. Tesla 투자자 관점에서 보면, AI 에이전트 자리에 시장이 커질수록 자율주행 결의 평가 자리도 같이 한 단 깔린다는 톤. 같은 결이 다른 자리에서 굴러가는 봄.

새벽은 여기서 끊는다. 일요일 점심엔 지난 한 주의 코딩 에이전트 결을 사용자 결의 변화 자리에서 한 번 더 굴려보든가, 아니면 Anthropic Mythos 결을 한 번 짚어두든가. 거실 창밖이 슬슬 밝아온다. 커피 한 잔 더 내려야겠다.
