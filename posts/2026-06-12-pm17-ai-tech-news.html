SpaceX가 SPCX로 박힌 첫날 — 진짜 무거운 줄은 xAI compute, Anthropic·Google이 월 21억 달러

퇴근 버스. 자리 잡고 폰 열자마자 SPCX 시초가 줄이 타임라인 위쪽에 떠 있었다. 1.75조 달러 valuation, 75억 — 아니 750억 달러 raise, 역사상 최대 IPO라는 결. 그런데 이 자리에서 진짜 무거운 칸은 시가총액 숫자가 아니다. SpaceX 안에 박힌 xAI가 Anthropic과 Google에 compute를 임대해서 받는 월 21억 달러 — 그 줄이 AI 인프라 분기 톤 자체를 바꾼다. 새벽 자리의 OpenAI 가격 카드 결과 정확히 반대편에 박힌 칸이라, 퇴근 버스에서 짧게라도 정리해 둔다.

SPCX 첫날 — Nasdaq 위 1.75조 달러

NPR 정리 톤대로 SpaceX가 $135에 555,555,555주를 박아 750억 달러를 raise. 1.75조 달러 valuation은 미국 상장사 중 7위쯤 — Tesla 시총 1.6조 달러 위에 SpaceX가 올라간 자리다. IndexBox 정리 톤은 총 수요가 2,500억 달러를 넘었고 그 중 리테일만 1,000억 달러를 넘은 결 — 30%를 리테일에 배정한 자리도 대형 IPO 자리에선 흔치 않은 칸.

엔지니어 시각에서 한 줄로 풀면 — SpaceX 안에 박힌 사업 칸이 Starlink 약 1,030만 가입자, xAI, Falcon·Starship. 그런데 TradingKey 정리 톤이 박은 S-1 숫자에서 Starlink가 분기 11.9억 달러 흑자, 우주 사업은 6.19억 달러 적자, AI 칸은 25억 달러 적자 — Connectivity만 영업이익이 박힌 자리고 나머지는 다 적자다. 1.75조 valuation을 받쳐주는 건 Starlink 가입자 곡선과 xAI compute 임대 라인 둘. Optimus·Robotaxi 없는 Tesla처럼, Starlink·xAI 없는 SpaceX는 valuation의 절반도 안 된다는 결이다.

진짜 무거운 줄 — xAI compute가 월 21억 달러를 박는다

IndMoney 정리 톤대로, xAI Colossus 1 데이터센터의 출력 전량을 Anthropic이 월 12.5억 달러에 2029년 5월까지 임대, Google은 2029년 6월까지 월 9.2억 달러. 합치면 월 21.7억 달러, 연 환산 약 260억 달러 compute 임대 매출. xAI가 Grok 라인 만으로 valuation을 받쳐주는 게 아니라, 다른 프론티어 랩의 compute 부담을 흡수하면서 임대료를 받는 자리가 진짜 칸이다.

이게 흥미로운 이유 — 어제 밤 자리에 깐 Anthropic Series H 9,650억 달러 valuation과 Apollo·Blackstone 35억 달러 데이터센터 라인이 같은 분기에 박힌 결과 정반대편에 서는 줄이다. Anthropic은 인프라를 굵게 박으면서 동시에 xAI의 Colossus를 통째로 임대하는 자리. 자체 데이터센터 + 외부 GPU 임대 두 줄을 동시에 굴리는 결인데, 새벽 자리에 정리한 Anthropic run-rate 300억 달러 매출 위에서 보면 compute 비용이 매출의 절반쯤이라는 그림이 드러난다. OpenAI가 Oracle Cloud 분포 라인을 깐 자리와 결이 정확히 다르다 — Anthropic은 임대, OpenAI는 분포.

X 자리에서 @elonmusk 톤은 "세계에서 가장 큰 AI 트레이닝 클러스터를 SpaceX 안에 박은 자리"를 박았고, @sama 톤은 "compute 임대 시장이 본격적으로 열렸다"는 줄을 한 칸 박았다. 프론티어 랩 사이의 compute가 직접 거래되는 자리가 본격화된 분기로 톤이 잡힌 결.

엔지니어 시각에서 풀면 한 칸 더 무거운 줄이 있다 — Anthropic이 자체 인프라(Apollo·Blackstone) + xAI Colossus 임대 + AWS Trainium2 라인까지 세 갈래 compute 스택을 동시에 굴린다는 결. 모델 학습 라인, 인퍼런스 서빙 라인, 에이전트 트래픽 라인을 분리해서 다른 GPU 자리에 박는 게 가능해진 분기. 회사 자리에서 TEM/SEM 영상처리 파이프라인을 학습·서빙·배치 추론으로 분리해서 굴리는 결과 결이 같다 — 하나의 거대한 클러스터가 아니라 목적별로 쪼개진 compute가 진짜 효율이라는 톤.

OpenAI Responses API — 같은 자리의 반대편 카드

OpenAI Responses API 라인 톤대로 6월 11일에 박힌 새 에이전트 API. Chat Completions의 단순함 + Assistants API의 도구 사용·상태 관리를 합친 자리에 web search, file search, computer use 빌트인 도구가 같이 깔린 결. Agentic 워크플로우를 한 API call로 굴릴 수 있게 만든 자리다.

엔지니어 시각에서 한 줄로 풀면 — 점심 자리에 박은 MCP·A2A 표준 합류와 같은 결인데, OpenAI는 자체 API에 도구 라인을 내장하는 칸을 골랐다. MCP는 외부 서버 자리에서 도구를 가져다 쓰는 구조고, Responses API는 OpenAI 클라우드 안에 도구가 깔린 구조. 표준은 합류, API는 분기라는 그림이 오늘 같은 시각에 한 칸 더 박혔다.

같은 자리에 한 줄 더. 새벽 자리에 정리한 OpenAI가 가격 카드를 만지작거린다는 줄과 이 Responses API 출시가 같은 결로 박혔다는 점. Anthropic이 코딩 에이전트 라인(Claude Code)에서 ARR을 박는 동안, OpenAI는 일반 에이전트 API 자리에서 가격·통합 두 칸으로 따라잡는 시계. 프론티어 랩 두 곳이 같은 분기에 다른 무기를 꺼낸 자리가 6월 톤의 핵심.

짧은 한 줄 — Tesla robotaxi 칸

퇴근 버스 자리에서 한 줄만 더 박아 둔다. TechTimes 정리 톤대로, Tesla unsupervised robotaxi 라인이 Austin 전역 245 평방마일로 6월 3일에 확장됐는데, 실제 가동 차량은 약 20대. Waymo 5세대 드라이버는 같은 시각 3,067대, 주 50만 건 유료 라이드. 숫자만 보면 42 vs 577로 한 칸 떨어진 자리.

Tesla 투자자 관점에서 보면 — FSD v15가 1B 파라미터에서 10B 파라미터로 모델 사이즈 한 자리 위로 박히는 아키텍처 재작성이 2026 말~2027 초 윈도우. 지금 20대 자리는 v15 깔리기 전의 임시 칸이고, 진짜 fleet 확장은 그 다음이라는 결. Barclays 6월 8일 톤은 robotaxi가 Tesla AI 사업의 가장 중요한 칸이라는 줄을 박았다 — Robotaxi 라인은 차량 수가 아니라 FSD 모델 사이즈가 진짜 변수라는 톤이 분석 자리에서 자리 잡는 결.

퇴근 한 줄

SpaceX가 Nasdaq에 박힌 첫날, 진짜 무거운 줄은 시총이 아니라 xAI compute 임대 매출이고, 그 자리에서 OpenAI는 에이전트 API로, Anthropic은 임대 + 자체 인프라 두 줄로 다음 분기를 준비하는 결이 한 시각에 같이 깔렸다. Compute가 매출이고, 모델이 자산이고, 에이전트가 분포라는 세 줄이 점점 또렷해지는 분기. 버스에서 내릴 시간 됐다 — 집 가서 디퓨전 모델 카드 다시 한 번 열어 보기로.
