Skills가 풀렸다 — 일요일 밤의 구조 변화 메모

일요일 밤. 이번 주는 모델 한 방의 주가 아니라, 에이전트 레이어의 공통 어휘가 생기기 시작한 주였다고 기록해두고 싶다.

Anthropic Agent Skills — 오픈 사양으로

Anthropic이 자사 Agent Skills를 오픈 사양으로 공개. 핵심은 둘.

  1. Skills 제작자는 Anthropic 에코시스템 밖으로 이식 가능
  2. OpenAI도 ChatGPT / Codex에서 구조적으로 동일한 아키텍처를 이미 채택 (보도 기준)

빅랩끼리 표준을 맞춘다는 신호가 공식적으로 나온 건 이번이 사실상 처음이다. 한 달 전 MCP가 Linux Foundation Agentic AI Foundation으로 이관된 것까지 엮어 보면, 분기 단위로 에이전트 인터페이스 레이어의 표준화가 밀린다.

표준화가 주는 진짜 의미

표준화는 언제나 양날이다.

  • 플러스 — 사용자/개발자 락인 해제, 제작된 툴의 수명 연장
  • 마이너스 — 모델·플랫폼 간 차별화 포인트 감소, 상품화 가속

이 구조 변화에서 경쟁은 위 레이어로 올라간다.

  • 에이전트 오케스트레이션 (멀티 에이전트 협업·플래너)
  • UX / 워크플로 통합 (어디에 박혀 있는가)
  • 인프라 비용 곡선 (토큰당 원가, 응답 지연)

나는 2026년의 진짜 승부처가 "어느 모델이 가장 똑똑한가"에서 "어느 플랫폼이 제일 비싸지 않게 깔려 있나"로 이동한다고 본다. 그 관점에서 Claude Opus 4.5의 67% 가격 인하 (11/24)도 같은 맥락으로 읽힌다.

GPT-5.2-Codex

12월 11일 GPT-5.2 본판에 이어 GPT-5.2-Codex가 별도 릴리스. 보고된 강화 포인트.

  • 장기 작업 컨텍스트 컴팩션 — 긴 호흡 작업에서 컨텍스트 압축 품질 향상
  • 대규모 변경(리팩터·마이그레이션) 성능 향상
  • Windows 환경 안정성
  • 사이버 보안 관련 성능 강화

특히 마지막이 눈에 띈다. "코딩 에이전트의 보안 작업" — 취약점 탐지·패치·시큐어 코드 생성 — 은 2026년 초반 엔터프라이즈 POC에서 이슈로 부상할 카테고리.

Gemini 3 Flash 기본 모델화

Google은 Gemini 3 Flash를 Gemini 앱과 AI Mode(검색)의 기본 모델로 올렸다. Gemini 3 풀버전 = 정확도, Flash = 단가·지연. 페어를 확실히 가른 모양새.

반도체 현직자 각도

표준화가 진행되면 추론 워크로드 포트abilityRC가 올라간다. 모델이 이식 가능해진다는 건 "어느 벤더의 가속기에서 돌려도 된다"는 의미고, 이건 Nvidia 독점을 점진 희석하는 축이다.

물론 단기적으론 Blackwell / Blackwell Ultra 수요가 여전히 타이트다. 하지만 2026년 후반으로 가면 AMD MI350 / Trainium3 / TPU v6 점유율이 의외로 올라올 여지가 생긴다. 이 축은 조용히 계속 지켜보고 있다.

다음 주

연말 휴가 구간. 발표는 줄지만 연말 회고 / 2026 전망 보고서가 쏟아질 시기. 개인적으로는 IDC·Gartner·ARK 리서치를 한 번에 묶어 읽어보려고 한다.

12월 키워드를 하나만 꼽으라면 "앰비언트(ambient)". 모델 발표가 이슈에서 브라우저·스프레드시트·메일에 그냥 깔리는 단계로. 그 변곡점이 이번 달에 통과된 것 같다.

일요일 밤, 여기까지.
