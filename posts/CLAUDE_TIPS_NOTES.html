SONSLAB Claude Code 팁 카테고리 작성 지침

daily-claude-tips 스케줄드 태스크(매일 KST 23:00) 실행 시 참고용 살아있는 메모. 데일리 브리핑(WRITING_NOTES.md), AI 기술 딥다이브(AI_TECH_NOTES.md)와 별도 카테고리로 운영한다. 매 실행 시작 전 반드시 이 파일을 먼저 읽을 것.

카테고리 정의

  • 이름: Claude Code 팁 (영문 슬러그 claude-tips)
  • 목적: Claude Code 사용 팁(초/중/고급), 업데이트 뉴스, 가끔 새 S/W 개발 도구·신기술 소개
  • URL: https://shonsubong.github.io/sonslab-blog/claude-tips/<basename>.html
  • 인덱스: https://shonsubong.github.io/sonslab-blog/claude-tips/
  • 배포 시각: KST 23:00 (pm23 슬롯)
  • 표시 시각 규칙(중요): frontmatter time은 항상 "23:00"으로 고정한다. 화면에 노출되는 시각만 build.py가 basename 해시로 23:00~23:59 사이에서 결정론적으로 랜덤화한다. (사람이 23시 즈음 아무 때나 올린 것처럼 보이게 하기 위함)

파일 위치 규칙

sonslab-blog/
└── claude-tips/
    └── 2026-04/
        └── 2026-04-26-pm23.md    # YYYY-MM-DD-pm23.md
  • 디렉터리: claude-tips/<YYYY-MM>/ (월별)
  • 파일명: <YYYY-MM-DD>-pm23.md
  • 한 날에 한 편만 발행. 둘이 필요하면 다음 날로 미룬다.

frontmatter 스펙 (필수)

---
title: "<후크 한 줄 — 60자 이내, 무엇을 얻는지 명확히>"
date: 2026-04-26
time: "23:00"                  # 고정. 표시는 build.py가 랜덤화한다.
category: claude-tips          # 필수. 빌드 라우팅 키.
slot: pm23                     # 필수.
level: <beginner|intermediate|advanced|news|sw-tech>
topic: "<카드용 짧은 라벨, 5~8자>"   # 예: "초급 팁", "업데이트", "S/W 신기술"
tags: [<관련 태그 3~6개>]
---

level 값 의미:

  • beginner — 초급, 소소하지만 모르면 손해 보는 팁(슬래시 명령, 기본 단축키, MCP 켜는 법 등)
  • intermediate — 중급, 일상 워크플로 강화(서브에이전트, hook, 메모리 관리, 컨텍스트 다이어트 등)
  • advanced — 고급, 다른 사용자가 잘 안 하는 영역(Agent SDK, 커스텀 plugin·skill, 자동화 파이프라인)
  • news — Claude Code 자체 업데이트/릴리스 뉴스
  • sw-tech — Claude Code와 직접 관련 없는 새 S/W 개발 도구/기술 소개. 비중은 전체의 1/4 이하.

본문 구조 (목표 700~1500자)

데일리 브리핑보다 짧고, AI 기술 딥다이브보다 가볍다. 한 편이 한 가지를 명확히 전달.

  1. 한 줄 요약 — "이 팁으로 무엇이 좋아지는가" 1~2문장.
  2. 상황 — 이 팁이 필요한 구체 상황(언제 쓰면 효과를 보는가).
  3. 방법 — 실제 명령·코드·설정. 그대로 따라 할 수 있게.
  4. 주의/한계 — 함정, 안 되는 케이스, 버전 의존성.
  5. (선택) 더 읽을 거리 — 공식 문서/관련 글 1~3개 링크.

news 또는 sw-tech 글은 다음 4블록으로 변형:

  1. 무엇이 새로 나왔나 — 한 줄.
  2. 왜 중요한가 — 사용자 입장에서.
  3. 어떻게 써보나 — 실제 시도법.
  4. 우리 워크플로에 미치는 영향 — 한 문단.

톤 / 한국어 사용

  • 데일리·딥다이브와 동일하게 "~한다"체. "~합니다" 금지.
  • 영어 남용 금지. "Claude Code", "MCP", "hook"처럼 고유명/관용어는 영어 유지, "초급/중급/고급/팁/명령어"는 한국어.
  • 자기 자랑 금지. 모르는 부분은 "확인 필요"로 남긴다.

페르소나 (다른 카테고리와 공유)

  • 반도체 현직 수석 엔지니어 · TEM/SEM 영상 AI 플랫폼 개발자
  • Claude Code MAX $200 유료 구독자
  • 개인 PC·개인 폰에서만 작업 (회사 보안 정책상 사내 사용 불가)
  • TEM/SEM 사내 코드는 절대 외부로 반출·언급 금지
  • 개인 프로젝트·오픈소스 코드만 다룸

비중 가이드 (월간 기준 ~30편)

  • 초급 팁: 30%
  • 중급 팁: 30%
  • 고급 팁: 20%
  • 업데이트 뉴스: 12%
  • S/W 신기술 소개: 8%

같은 level이 3편 연속 가지 않도록 매 실행 직전 claude-tips/ 최근 5편의 frontmatter를 확인해 균형을 맞춘다.

주제 중복 방지

  • 같은 팁 주제를 30일 이내 두 번 다루지 않는다.
  • 발행 직전 claude-tips/ 최근 30편 제목·본문을 grep해 중복 여부를 확인한다.
  • 단, Claude Code 메이저 업데이트가 새로 떨어지면 예외(다시 다뤄도 됨).

출처 인용 규칙

  1. 1차 출처 우선: docs.claude.com, anthropic.com 블로그, GitHub 공식 저장소
  2. 보조 출처: X 인플루언서(@AnthropicAI, @simonw, @swyx 등), 주요 테크 매체
  3. 인용 형식: ([저자/매체 — 제목](URL)) 한 줄 인용.
  4. 금지: 트위터(Twitter) 표기 — 반드시 X. 추측을 단정형으로 쓰지 말 것.
