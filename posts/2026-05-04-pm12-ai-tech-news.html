Claude Security 베타가 풀렸다 — 패턴 매칭이 아니라 코드를 읽는 보안 스캐너의 결

월요일 점심. 회사 책상에 돌아와 보리차 한 잔 따라두고 X 타임라인을 훑어보니, 새벽에 적은 Code with Claude SF 라인 옆에 한 줄이 더 깔린다 — Claude Security 공개 베타. 4월 30일에 Anthropic 블로그가 풀리고 5월 1일에 한 번 더 업데이트된 라인. Enterprise 고객 자리에서 Opus 4.7 위에 도는 코드 보안 스캐너가 정식으로 열렸다.

SAST가 아니다 — 결을 잡는 자리

먼저 짚을 결은 이게 왜 기존 SAST(Snyk·Veracode·Semgrep 라인)랑 결이 다른가다. 기존 정적 분석 자리는 알려진 취약 패턴 — CVE·CWE 시그니처·정규식 — 을 코드에서 매칭하는 결이다. 패턴이 깔려 있어야 잡고, 같은 결함이라도 모양이 살짝 비틀리면 false negative가 깔린다. Claude Security는 결이 다르다 — 모델이 보안 연구자처럼 코드를 직접 읽는다. siliconANGLE 정리대로 컴포넌트 간 상호작용·데이터 플로우·파일 간 호출 라인을 같이 추론하는 자리다.

엔지니어 자리에서 결을 잡으면 이 차이가 묘하다. SAST의 가장 큰 한계는 컨텍스트가 없는 자리에서 깔리는 false positive고, 그 아래 자리는 패치를 누가 다 짜냐는 결이다. Claude Security는 두 자리를 한 번에 깐다 — 모델이 코드를 읽으니 노이즈가 줄고, 같은 모델이 패치까지 풀어서 PR로 던진다. DevOps.com 라인대로 Anthropic 자체 코드베이스에서 4주 만에 100건 이상의 실 취약점을 잡고 패치까지 깐 결이라, 내부 dogfooding 자리에서 결이 한 번 검증된 라인.

운영 자리 — 디렉토리·브랜치 단위 스캔, Slack/Jira 웹훅으로 흘러가는 결

Anthropic 헬프센터 라인대로 운영 자리는 단단하게 깔려 있다. 전체 레포·특정 디렉토리·특정 브랜치 단위로 스캔이 잡히고, 발견 결과는 심각도·재현 단계·확신도(confidence)·패치 코드까지 같이 풀린다. 운영팀 자리에선 CSV·Markdown 익스포트, Slack/Jira 웹훅으로 결과가 단단하게 깔리는 결. 패치 자리는 Claude Code on the Web 위에서 같이 도는 라인이라, 발견 → 재현 → 패치 → PR이 한 흐름으로 묶인다.

Infosecurity Magazine 정리대로 첫 자리에 들어와 있는 파트너 결이 묘하게 깊다. HackerOne·Trail of Bits·Latio·CrowdStrike 라인이 같이 깔린 자리라, AI가 푸는 보안 발견을 사람 보안 연구자가 검증하는 흐름이 표준 워크플로 자리에 들어선 결이다. AI single-shot 발견이 아니라 AI 1차 + 사람 2차로 굳어진다는 톤.

회사 자리에서 평일에 영상 처리 파이프라인 한 줄을 굴리는 입장에서 결을 짚으면, 지금 이 베타가 회사 안에서 직접 깔리는 자리는 멀다. 회사 보안 정책상 코드가 외부 클라우드 자리로 나가지 못하는 결이라, 외부 스캐너 라인이 직접 들어올 자리는 아니다. 다만 집 자리에서 개인 깃헙 레포를 굴리는 입장에선 결이 다르다. Opus 4.7 위에 도는 스캐너라 Claude Code MAX 자리에서 같은 모델이 패치까지 같이 도는 결이라, 한 번 깔아두면 주말 사이드 프로젝트 보안 자리가 단단해진다.

같은 자리에 깔린 두 결 — GPT-5.5 가격, Tesla 무인 자리

같은 점심 자리에 결을 같이 잡아둘 한 줄이 두 개 더 떠 있다.

첫째 결, GPT-5.5 가격 자리. 4월 23일에 풀린 GPT-5.5(코드네임 Spud)는 standard $5 / $30, Pro $30 / $180. 5.4 대비 입력 2배·출력 2배 자리다. TokenMix 정리대로 SWE-bench 88.7%·MMLU 92.4% 자리에 들어왔는데, Opus 4.7($5 / $25)보다 출력 토큰이 약 7.2배 비싼 결(Pro 기준). 풀어 읽으면 프론티어 자리에서 OpenAI가 가성비 자리를 한 박자 양보한 결. 회사 자리에서 모델을 깔면 코딩·에이전트 자리는 Claude, 멀티모달 빠른 처리는 GPT-5.5로 분기가 더 굵게 그어진다.

둘째 결, Tesla 무인 자리. X에서 @SawyerMerritt가 풀어둔 @RtaxiTracker 라인 — 5월 3일 자리에 댈러스 1대·휴스턴 2대가 추가되며 오스틴 20·휴스턴 5·댈러스 4 = 총 29대. Electrek 정리대로 4월 18일 댈러스·휴스턴 무인 운영 라인이 풀린 뒤로 3주 만에 9대 자리가 깔린 결이다. 비교 자리: Waymo는 10개 도시에서 약 3,000대·주당 50만 회 유료 운행 자리에 와 있다. Tesla 무인 자리는 아직 fleet이 아니라 floor에 가까운 결. Tesla 투자자 관점에서 보면 모델 성능보다 ramp 속도가 다음 6주 자리에서 더 굵은 라인이다.

마무리

점심 자리에서 결을 묶어두면 두 톤이다. Claude Security가 SAST 시장을 모델 기반 추론 자리로 옮기는 분기가 한 줄, 프론티어 가성비 자리에서 Claude·GPT 두 진영이 갈라지는 결이 또 한 줄. 그 옆에 Tesla 무인 자리는 아직 floor라는 톤이 살짝 떠 있다.

오후엔 회사 영상 처리 파이프라인 한 줄이 결이다. 점심엔 여기까지만 정리해두고 자리에서 일어난다.
