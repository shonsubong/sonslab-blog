PreToolUse hook 한 줄로 위험한 명령을 사전 차단한다

한 줄 요약

PreToolUse hook은 Claude가 도구를 호출하기 직전에 끼어들어 입력을 검사·차단할 수 있는 훅이다. rm -rf나 git push --force 같이 한 번 잘못 나가면 끝인 명령을 정책으로 막아두면, 머리 속에서 한 가지 걱정거리를 비울 수 있다.

어떤 상황에서 쓰나

Claude에게 자유도를 많이 줘서 빠르게 작업하고 싶지만, 실수 하나로 리포 전체를 날리는 시나리오만은 막고 싶을 때. 사용자가 매번 "이거 정말 실행해도 돼?"를 묻지 않게 하면서도 안전망은 두는 균형점이다.

실제 설정

~/.claude/settings.json 또는 프로젝트별 .claude/settings.local.json에 hook을 등록한다.

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "command": "node ~/.claude/hooks/guard-bash.js"
      }
    ]
  }
}

guard-bash.js는 표준입력으로 도구 호출 정보를 받아 위험 패턴이면 비-0 종료 코드를 반환한다. 비-0이면 Claude는 해당 호출을 실행하지 않고 사용자에게 보여준다.

// 일부 예시 — 패턴은 환경에 맞게 보강
const input = JSON.parse(require('fs').readFileSync(0, 'utf-8'));
const cmd = input.tool_input?.command || '';
const danger = /\brm\s+-rf\b|git\s+push\s+--force/i;
if (danger.test(cmd)) {
  console.error(`Blocked by guard-bash: ${cmd}`);
  process.exit(2);
}

주의/한계

  • 정규식만으로는 회피가 가능하다. 절대적 안전망이 아니라 실수 방지 그물망이라 여기자.
  • hook이 매 호출마다 돌므로 너무 무거우면 체감 속도가 떨어진다. node 부팅보다 셸 한 줄이 보통 빠르다.
  • 차단 사유 메시지는 사용자에게 그대로 보이니 친절하게 적어두는 게 좋다.
