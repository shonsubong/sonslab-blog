Output styles — Claude Code의 응답 스타일을 통째로 갈아 끼운다

한 줄 요약

Output style은 Claude Code의 기본 시스템 프롬프트 일부를 통째로 다른 페르소나로 갈아 끼우는 장치다. CLAUDE.md에 "한국어로만 답해라", "긴 사설 빼라"를 매번 박아두던 패턴이, 한 번 정의해 놓고 /output-style로 골라 쓰는 형태로 깔끔하게 옮겨간다.

어떤 상황에서 쓰나

CLAUDE.md를 페르소나·톤 지시로 채우다 보면 두 가지가 거슬린다. 첫째, 매 세션 토큰을 그만큼 깐 채로 시작한다. 둘째, "이 세션은 코딩 보조"인지 "이 세션은 한국어 글쓰기 보조"인지 톤이 한 파일 안에서 충돌한다. Output style을 쓰면 CLAUDE.md에는 프로젝트 사실(빌드 명령, 테스트 규칙)만 남고, 페르소나는 별도 마크다운 한 장으로 분리된다. 한 저장소에서 코드 작업과 문서 작업을 오가는 사람이 가장 큰 효과를 본다.

실제 만드는 법

위치는 ~/.claude/output-styles/<이름>.md(전역) 또는 <repo>/.claude/output-styles/<이름>.md(프로젝트). 파일명이 곧 스타일 키다.

---
name: ko-terse
description: 한국어 ~다체. 사설 짧게, 코드 인용은 그대로.
---

당신의 모든 자연어 응답은 한국어 "~한다"체다.
- 사설·자기 자랑·요약 후미는 쓰지 않는다.
- 코드 블록·명령·파일 경로는 원문 그대로 둔다.
- 확인 못 한 사실은 "확인 필요"로 남긴다.

세션 안에서 /output-style ko-terse로 적용한다. 아무 인자 없이 /output-style만 치면 등록된 스타일 목록과 현재 활성 스타일이 보인다. CLI 시작 시 바로 적용하고 싶으면 claude --output-style ko-terse를 쓴다. 새 스타일을 인터랙티브로 만들고 싶으면 /output-style:new 한 줄에 자연어로 원하는 톤을 적어주면 Claude가 마크다운을 생성해준다.

핵심은 본문이 CLAUDE.md와 다른 위치에서 "톤·언어·답변 형식"만 책임진다는 점이다. 프로젝트 사실은 CLAUDE.md에, 페르소나는 output style에, 절차는 SKILL.md에 — 세 위치가 역할이 깔끔하게 갈린다.

주의/한계

  • Output style은 시스템 프롬프트의 일부를 대체한다. 도구 사용 규칙·안전 규칙까지 갈아엎는 게 아니라, "응답 톤"을 책임지는 블록만 바꾼다는 점을 기억해두자. 강하게 바꿀수록 도구 호출 흐름이 살짝 흔들릴 수 있어, 코딩 작업용 스타일은 비교적 짧게 두는 편이 안전하다.
  • CLAUDE.md와 output style이 충돌하는 지시(예: 톤 지정)를 동시에 박아두면 우선순위가 헷갈린다. 톤·언어는 output style에 몰고, CLAUDE.md에서는 빼는 게 가장 깔끔하다.
  • 사내 코드·민감 데이터를 본문에 적지 말 것. 호출되는 순간 컨텍스트로 흘러간다.
  • 슬래시 명령 이름은 클라이언트 버전에 따라 미세하게 다르다. 안 잡히면 /help로 현재 세션의 정식 이름을 한 번 확인한다.
