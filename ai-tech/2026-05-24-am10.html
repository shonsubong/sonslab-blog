4비트로 10조 토큰을 학습했다 — NVFP4가 FP8을 따라잡은 방식

AI 딥다이브 2026년 05월 24일 (일) · 10:00 · 5분 읽기
목차

  • 배경

TL;DR

  • NVIDIA가 12B 하이브리드 Mamba-Transformer를 10조 토큰까지 전부 4비트(NVFP4)로 사전학습하고, FP8 대비 검증 손실 차이를 안정 구간에서 1% 이내로 묶었다. 공개된 4비트 학습 중 최장 기록이다.
  • 비결은 포맷(16값 블록·이중 스케일)과 레시피(랜덤 Hadamard 회전, 확률적 반올림, 일부 층만 고정밀)의 결합이다. FP4의 약점인 블록 최댓값 오차를 구조적으로 깎았다.
  • 같은 흐름에서 MIT·NVIDIA의 "Four Over Six"가 같은 오차를 2% 미만 오버헤드로 더 줄였다.

배경

5월 18일 NVFP4 사전학습 레시피가 다시 화제에 올랐다. 12B 하이브리드 모델을 10T 토큰까지 4비트로 돌린 결과가 재조명되면서다 (MarkTechPost).

그동안 4비트는 추론 압축용이지 학습 정밀도는 아니라는 게 상식이었다. FP8조차 안정화에 애를 먹었는데, 그 절반 비트로 멀티트릴리언 토큰 학습이 FP8과 맞먹는다는 건 컴퓨트 예산의 전제를 흔든다. MMLU 76.57 대 77.36, GSM8K 92.27 대 89.08처럼 다운스트림이 FP8과 엎치락뒤치락이다 (NVIDIA arXiv 2509.25149). Blackwell의 FP4 텐서코어가 깔리는 시점과 맞물려 사전학습을 통째로 4비트로 내리려는 시도가 줄을 잇는다.

핵심 메커니즘

NVFP4가 MXFP4와 갈리는 첫 지점은 블록 크기와 스케일이다. 32개 값이 스케일 하나를 공유하는 MXFP4와 달리, NVFP4는 16값마다 E4M3 스케일을 붙이고 그 위에 텐서 단위 FP32 스케일을 한 겹 더 얹는다(이중 스케일). 블록이 좁을수록 한 스케일이 떠안는 동적 범위가 줄어 최댓값 근처 오차가 작아진다.

입력 텐서 ─▶ [RHT 회전: 이상치 분산] ─▶ [16값 블록 · E4M3 스케일] ─▶ [텐서 FP32 스케일] ─▶ FP4 GEMM
gradient ─▶ [확률적 반올림: 편향 0 추정] ─────────────────────────────────────────┘

레시피는 세 축이다. 첫째, 랜덤 Hadamard 변환(RHT)으로 텐서를 회전해 블록 안 이상치를 흩는다. 둘째, 순전파·역전파가 같은 수를 보도록 2차원 양자화를 쓴다. 셋째, gradient에만 확률적 반올림으로 편향 없는 추정을 만든다. 민감한 일부 층은 고정밀로 남긴다.

코드 / 수식

확률적 반올림의 핵심은 기댓값이 원값과 같다는 점이다.

# gradient에만 적용
def stochastic_round(x, x_lo, x_hi):
    p = (x - x_lo) / (x_hi - x_lo)
    return x_hi if random() < p else x_lo
# E[round(x)] = p*x_hi + (1-p)*x_lo = x  →  반올림 편향 0

# Four Over Six: 블록 최댓값 오차를 줄이는 적응 스케일
scale = block.absmax / 6.0   # 4 대신 6으로 나눠 상단 해상도 확보

FP4(E2M1)는 정수형과 달리 최댓값 근처에서 오차가 가장 크다. 지수가 커질수록 표현 간격이 벌어진다. "Four Over Six"는 일부 블록을 더 작은 FP4 값으로 적응 스케일해 표현값 분포를 평탄하게 만들고, 이 한 수로 학습 발산을 여러 사례에서 막았다 (Cook et al.).

한계·반론

좁은 블록(16)이 양날이다. 학습엔 유리하지만 추론 후처리 양자화에선 전통적 이상치 완화 기법을 무력화한다는 보고가 있다. 채널 단위 보정이 잘 안 먹혀 ARCQuant·Four Over Six 같은 NVFP4 전용 기법이 따로 나온다 (Rohan Paul X).

손실 차이가 1% 이내라지만 decay 구간에선 1.5%까지 벌어진다. "거의 같다"가 "같다"는 아니다.

모든 이점은 Blackwell FP4 텐서코어 전제다. H100 세대엔 NVFP4 가속이 없어 INT4(AWQ) 경로가 여전히 현실적이다. 하드웨어 종속이 강하다.

현직 엔지니어 관점

반도체 쪽에서 이 결과의 무게는 "비트 폭이 곧 실리콘 면적·전력"이라는 데서 온다. FP8 대비 2~3배 연산 처리량과 약 1.8배 메모리 절감은 같은 다이로 더 큰 모델을 학습한다는 뜻이자 메모리 월을 한 칸 미루는 일이다. 다만 RHT와 확률적 반올림은 공짜가 아니라 데이터패스에 회전·난수 로직을 더한다. 포맷 이득을 깎아먹지 않게 이 오버헤드를 숨기는 게 설계의 핵심이다.

온디바이스로 내려오면 함의가 더 크다. 학습이 4비트로 수렴한다면 단말 추론을 같은 포맷으로 통일해 학습-배포 간 양자화 간극을 줄일 수 있다. 현장에서 영상 판정 모델을 엣지로 내릴 때 늘 발목 잡는 게 이 간극인데, 학습부터 저비트 분포를 본 모델은 후처리 양자화 손실이 작을 여지가 있다. 16값 블록의 추론측 약점은 그대로라, 당분간은 "학습은 NVFP4, 추론은 별도 기법"이 현실적 조합이다.
