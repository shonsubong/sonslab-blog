오픈 모델의 천장이 2.8조가 됐다 — Kimi K3와 KDA의 계산

AI 딥다이브 2026년 07월 17일 (금) · 10:00 · 5분 읽기

TL;DR

  • Moonshot AI가 어제(7/16) 2.8조 파라미터 오픈웨이트 MoE 모델 Kimi K3를 공개했다. 오픈 모델 사상 최대 규모다 (Moonshot AI — Kimi K3 Tech Blog).
  • 핵심은 크기가 아니라 어텐션이다. Gated DeltaNet을 확장한 선형 어텐션 KDA(Kimi Delta Attention)로 1M 토큰 컨텍스트에서 디코딩을 최대 6.3배 빠르게 만들었다.
  • 가격은 캐시 히트 입력 $0.30/MTok. 코딩 캐시 히트율 90% 이상 주장이 맞다면 프런티어급을 이 값에 쓰는 셈이다.

배경 (Why now)

7월은 모델 러시였다. Grok 4.5, GPT-5.6, Claude Sonnet 5가 몇 주 간격으로 나왔고, 그 끝에 Moonshot이 K3를 내놨다. 2.8조 파라미터는 DeepSeek V4 Pro(약 1.6조)보다 75% 크고, 오픈웨이트 모델의 상한을 다시 끌어올렸다 (VentureBeat — China's Moonshot AI releases Kimi K3).

Moonshot 스스로 "전체 성능은 Claude Fable 5와 GPT-5.6 Sol에 못 미친다"고 인정하면서도, SWE Marathon(42.0 vs Fable 5의 35.0)과 BrowseComp(91.2) 같은 장기 에이전트 과제에서는 앞선다고 주장한다. 최전선을 정면으로 이긴 게 아니라 긴 호흡의 작업에서 강점을 만든 셈이다.

핵심 메커니즘

K3의 기술적 본질은 KDA다. 표준 어텐션은 시퀀스 길이 n에 대해 $O(n^2)$ 계산과 계속 자라는 KV 캐시가 필요하다. KDA는 고정 크기 상태를 갱신하는 선형 어텐션이라 컨텍스트가 길어져도 상태 크기가 일정하다. Gated DeltaNet에 채널 단위의 세분화된 게이트를 더해, 유한한 RNN 메모리에 무엇을 남기고 무엇을 지울지를 채널별로 결정한다 (arXiv — Kimi Linear: An Expressive, Efficient Attention Architecture).

다만 순수 선형 어텐션만으로는 정밀한 검색(retrieval) 성능이 떨어지므로, 전체 레이어를 KDA와 전역 어텐션(MLA)의 하이브리드로 구성한다. Kimi Linear 공개 구현 기준 비율은 3:1이다 (GitHub — MoonshotAI/Kimi-Linear).

[토큰 입력]
   ├─ KDA 레이어 ×3   : 고정 크기 상태 갱신 (지울 것/남길 것 게이트 결정)
   └─ MLA 레이어 ×1   : 전역 어텐션으로 정밀 검색 보완
        ↓ 반복
[Stable LatentMoE]    : 896개 전문가 중 16개만 활성화
        ↓
[출력]  — KV 캐시 대폭 축소, 1M 컨텍스트 디코딩 최대 6.3배

깊이 방향으로는 AttnRes가 있다. 잔차 연결을 그대로 누적하는 대신 층을 건너 선택적으로 표현을 가져와, 추가 비용 2% 미만에 학습 효율을 약 25% 올렸다고 한다.

코드 예시

KDA의 상태 갱신을 의사코드로 적으면 델타 규칙에 게이트가 붙은 형태다.

# KDA 상태 갱신 (개념 의사코드)
# S: 고정 크기 상태 행렬, alpha: 채널별 망각 게이트
for t in range(seq_len):
    k, v, q = proj_k(x[t]), proj_v(x[t]), proj_q(x[t])
    beta  = sigmoid(w_b @ x[t])          # 갱신 강도
    alpha = sigmoid(w_a @ x[t])          # 채널별로 얼마나 지울지
    # 델타 규칙: 기존 기억에서 k방향 예측 오차만큼만 교체
    S = diag(alpha) @ S + beta * outer(v - S @ k, k)
    y[t] = S @ q                          # KV 캐시 없이 상태에서 즉시 계산

핵심은 alpha가 스칼라가 아니라 채널별 벡터라는 점이다. Gated DeltaNet의 게이트를 잘게 쪼갠 것이 KDA의 차별점이고, 이 덕분에 같은 크기의 상태로 더 오래 유효한 정보를 유지한다.

한계·반론

벤치마크는 전부 Moonshot 자체 평가 수치다. 발표 당일 X에서는 "Opus 티어를 무의미하게 만들었다"는 반응까지 나왔지만, 독립 검증 전의 런칭 나이트 스레드는 벤더 카드가 아니라는 지적도 바로 따라붙었다 (OfficeChai — Kimi K3 Benchmarks). HLE-Full(43.5 vs Fable 5의 53.3)과 FrontierSWE에서는 열세가 뚜렷하다.

"오픈"의 실질도 따져야 한다. 권장 서빙 구성이 가속기 64장 이상의 슈퍼노드다. 가중치를 받을 수 있다는 것과 돌릴 수 있다는 것은 다르다. KDA는 프리픽스 캐싱과 궁합이 나빠 Moonshot이 vLLM에 별도 구현을 기여해야 했을 정도로, 새 어텐션 구조는 서빙 생태계가 따라와야 실전 투입이 가능하다.

현직 엔지니어 관점

2.8조짜리 모델 자체는 개인이 만질 물건이 아니다. 그런데 KDA의 방향은 온디바이스에 그대로 적용된다. 고정 크기 상태는 곧 예측 가능한 메모리 사용량이고, DRAM이 빠듯한 엣지 장비에서 긴 컨텍스트를 다루기 위한 필수 조건이다. 실무자에게는 Moonshot이 먼저 공개한 Kimi Linear 48B-A3B 체크포인트와 FLA 커널이 오히려 더 유용한 산출물일 수 있다. MXFP4 가중치·MXFP8 활성화를 SFT 단계부터 양자화 인지 학습으로 넣은 것도 눈여겨볼 부분이다. 저정밀 포맷을 학습 후 변환이 아니라 학습 과정에 포함시키는 흐름은 NPU 하드웨어 설계에도 시사점이 있다.
