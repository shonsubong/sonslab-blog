129개 갈림길에서 사람보다 64% — Anthropic이 그린 자기개선 척도

AI 딥다이브 2026년 06월 12일 (금) · 10:00 · 5분 읽기
목차

TL;DR

  • 지난주 Anthropic Institute가 공개한 "When AI builds itself" 리포트에 자기개선(RSI) 측정용 내부 메트릭이 처음 외부로 노출됐다 (Anthropic Institute — When AI builds itself).
  • 핵심 숫자: 사내 Claude Code 세션에서 추린 "Hard Moments" 129개 중 64%에서 모델 제안이 사람 선택보다 낫게 평가됐다. 2025년 11월 Opus 4.5가 51%였으니 다섯 달 만에 13%p 올랐다.
  • 같은 보고서에 학습 코드 자동 최적화 벤치도 같이 묶였다. Opus 4(2025-05) 3배 → Mythos Preview(2026-04) 52배 — 사람이 4~8시간 걸리는 작업이다.

배경 — 왜 새 메트릭이 필요했나

SWE-Bench, HumanEval, METR 시간 지평선 같은 외부 벤치는 사실상 포화로 가고 있다 (METR — Time Horizons). Opus 4.5 이후로는 코드 정답률만 봐서는 모델 격차가 잘 안 잡힌다. 그런데 사내에서는 Claude의 비중이 빠르게 커졌다. 5월 기준 사내 코드 머지의 80% 이상을 Claude가 썼고, 엔지니어 1인당 일일 머지 라인 수는 2024년 대비 8배다.

이 격차를 어떻게 잡나. "답을 맞히는가"가 아니라 "다음 한 수를 잘 고르는가"로 질문을 바꿔야 한다. 그래서 나온 게 Hard Moments다.

핵심 메커니즘 — Hard Moments 채집 방식

실제 사내 Claude Code 세션(2026-01~03) 중에서 "사람이 잘못된 방향으로 옆길을 탔다가 결국 본궤도로 돌아온 순간"만 골라낸다. 이 순간이 갈림길 표본 1개다.

[세션 기록 전체]
       │
       ▼
[옆길로 빠진 순간 t] ──┬──→ [t 이전 컨텍스트만] → 후보 모델 A
       │              │
       │              └──→ [실제 사람 선택]    → 기준선 B
       ▼
[세션 결말까지 본 Claude 심판] → "A와 B 중 누가 더 좋은 다음 수?"

핵심은 심판 모델이 결말을 다 보고 판단한다는 점이다. 후보 모델은 그 시점까지의 정보만 본다. 표본은 129개로 작지만 매번 "사람이 헷갈렸던 곳"을 골라낸 거라 난도가 높다.

편향 검증도 같이 돌렸다. 사람의 선택이 강했던 표본 127개에서는 모델 승률이 약 20%로 떨어진다. 심판이 모델 편을 든 게 아니라 원래 표본 자체가 "사람이 잘 막히는 영역"이라는 뜻이다.

코드 — 사후 심판 패턴의 의사 표현

def hard_moment_eval(session, t, model):
    # 1) 후보의 다음 수 — t 이전 컨텍스트만 본다
    ctx_partial = session.truncate(t)
    move_model  = model.propose_next(ctx_partial)
    move_human  = session.actual_action_at(t)

    # 2) 결말을 본 별도 Claude가 둘을 비교
    judge_ctx = {
        "before_t": ctx_partial,
        "after_t":  session.tail_from(t),  # 결말 포함
    }
    winner = claude_judge.compare(
        judge_ctx, move_model, move_human
    )
    return winner  # "model" | "human" | "tie"

함정은 둘이다. 심판이 결말을 알고 본다는 점에서 일반 LLM-as-Judge보다 강한 사후 시야를 가진다. 그리고 모델과 심판이 모두 Claude 계열이라 자기편애가 끼어들 수 있다. 후자를 막은 게 반대편 표본 127개 캘리브레이션이다.

한계·반론

표본 129개는 작다. 51%와 64%의 통계적 유의성이 표본 크기만 보면 위태롭다.

둘째, "사람이 길을 잘못 잡은 순간만 뽑았다"는 점이다. 사람의 평균이 아니라 약점만 모은 표본이라 "사람보다 64%"를 일반화하면 그림이 틀어진다.

셋째, 외부 검증 불가다. 약한 모델이 강한 모델을 감독하는 사내 자동화 연구도 프로덕션 규모에서는 결과가 매끄럽게 전이되지 않았다 (Anthropic Alignment — Automated W2S Researcher). Tom's Hardware는 이 보고서를 두고 "RSI 임박 신호인지, 더 많은 컴퓨트 확보 캠페인인지"를 물었다 (Tom's Hardware — Anthropic warns AI self-improvement).

현직 엔지니어 관점

반도체 R&D에서도 비슷한 측정 함정이 있다. 신뢰성 시험에서 "장비가 사람보다 결함을 잘 찾는가"를 따질 때 사람이 놓친 케이스만 모아 비교하면 장비 승률이 부풀려진다. 그래도 그 표본이 쓸모 있는 건 사람이 어디서 자주 막히는지를 알려주기 때문이다. Hard Moments도 같다 — RSI 임박 신호로 읽기보다 사람이 어떤 결정 지점에서 잘못 가는지의 분포로 보는 게 안전하다. 온디바이스 코드 에이전트도 다음 측정선은 "정답률"이 아니라 "사람이 헷갈리는 순간 어디까지 따라잡았나"다.
