# 한·영 용어 표기 통일

두 권에서 같은 개념을 같은 말로 쓴다. 왼쪽이 본문 표기, 오른쪽이 설명/주의.

## 핵심 개념

| 본문 표기 | 설명 / 표기 주의 |
|-----------|------------------|
| Claude Code | 절대 "클로드코드" 붙여쓰기 금지. 영문 원형. 한글 병기 시 "클로드 코드" |
| 에이전트 루프 (agent loop) | 첫 등장 시 영문 병기, 이후 "에이전트 루프" |
| CLAUDE.md | 항상 영문·대문자. "프로젝트 메모리 파일"로 풀어 설명 가능 |
| 메모리 | `#` 입력과 `/memory`로 관리하는 영구 지침 |
| 슬래시 명령 | `/`로 시작하는 명령. "슬래시 커맨드" 대신 "슬래시 명령" |
| Plan 모드 | 번역하지 않음. "계획 모드"로 풀어쓰기 가능 |
| 권한 (permissions) | allow/ask/deny 규칙 |
| MCP | Model Context Protocol. 첫 등장만 풀어쓰고 이후 MCP |
| Skills | "스킬". 특정 작업 모범 사례 묶음 |
| Hooks | "훅". 자동 실행 후크 |
| Subagents | "서브에이전트" |
| Plugins | "플러그인" |
| Agent SDK | 영문 원형 |
| Worktree | "워크트리". 병렬 세션 격리 |
| Agent View | 신기능(2026-05). 여러 세션 한 화면 관리 |
| `/goal` | 조건 충족까지 자율 진행(2026-05) |
| Dynamic workflows | "다이내믹 워크플로". 스크립트 오케스트레이션(2026-05) |
| 딥 링크 | `claude-cli://` 세션 바로 열기(2026-04) |
| 바이브 코딩 | vibe coding. 자연어로 맡기는 코딩 |
| 컨텍스트 | context. "맥락"으로 풀어쓰기 가능, 용어로는 "컨텍스트" |
| 토큰 | token |

## 표기 원칙

- 처음 나오는 영문 약어/제품명은 **(영문 또는 한글 병기)** 1회, 이후 통일 표기.
- 동사화: "커밋한다", "푸시한다"는 허용. 억지 순화("맡기기") 금지.
- 숫자·단위: 한글 문장 안에서도 아라비아 숫자("30분", "3개").
