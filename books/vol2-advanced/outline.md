## Part 2. 환경 확장 — MCP·Skills·Hooks·Subagents (중급 핵심)

- 학습 목표: 외부 시스템을 도구로 붙여 작업 범위를 넓힌다.
- 핵심 개념: MCP 개념, 서버 연결, 인기 서버 톱 N.
- 실습: 인기 MCP 1개 연결 후 실제 작업.
- 함정: 인증·권한 충돌 → 점검 순서.

### 2-2. 나만의 MCP 서버 만들기

- 핵심 개념: 서버 구현, 도구 스키마.
- 실습: 최소 MCP 서버 작성→연결.
- 분량: 10p · 원천: #18

### 2-3. Skills — 반복 작업을 모범 사례로 박제
- 학습 목표: 팀의 작업 방식을 스킬로 고정한다.

- 메모: **이 책 자체가 스킬로 쓰여졌음**을 실증 사례로 활용.
