# Vol.1 — 클로드 코드, 오늘 처음 켜는 사람을 위한 책 (초급)

> **한 문장 약속**: 코딩을 몰라도, 오늘 저녁 안에 내 손으로 동작하는 앱 하나를
> 만든다.
> **대상 독자**: 터미널은 처음이거나 어색한 비전공자~입문 개발자. AI 코딩 도구를
> 써본 적 없는 사람.
> **끝낸 뒤 할 수 있는 일**: 혼자서 Claude Code를 설치하고, 프로젝트를 만들고,
> 막힐 때 빠져나오고, 작은 앱을 끝까지 완성한다.

기준 버전: v2026.22 (주간 갱신 → `../weekly/README.md`)

## Part 1. 시작 — 겁먹지 않기 (1일 차)

### 1-1. Claude Code가 뭐길래
- 학습 목표: 이 도구가 무엇을 대신해 주는지 한 문장으로 설명할 수 있다.
- 선수 지식: 없음.
- 핵심 개념: AI 코딩 에이전트, 터미널, 자연어 지시.
- 실습: 없음(읽기). 대신 "할 수 있는 일 5가지" 사례.
- 함정: "개발자만 쓰는 것"이라는 오해 → 비전공 사례로 해소.
- 분량: 6p · 원천: manifest #1

### 1-2. 설치 — 막히는 곳만 콕 집어
- 학습 목표: 내 컴퓨터(Win/Mac)에 설치하고 첫 실행을 본다.
- 선수 지식: 1-1.
- 핵심 개념: 설치, 로그인/인증.
- 실습: 설치 → `claude` 실행 → 인사 한마디 받기.
- 함정: 권한·경로·로그인 3대 막힘. OS별 해결 박스.
- 분량: 10p · 원천: #2, #3

### 1-3. 첫 5분 — 말 걸고, 시키고, 확인하기
- 학습 목표: 자연어로 시키고 결과를 받아 본다.
- 핵심 개념: 프롬프트, 권한 승인, 파일 변경 확인.
- 실습: "이 폴더에 인사하는 파일 만들어 줘" → 결과 확인.
- 함정: 승인 창에서 멈칫 → 무엇을 묻는지 그림으로.
- 분량: 8p · 원천: #4

### 1-4. 안에서 무슨 일이 — 에이전트 루프 쉽게
- 학습 목표: AI가 '읽고-생각하고-고치고-확인'을 반복함을 안다.
- 핵심 개념: 에이전트 루프(개념만).
- 실습: 같은 작업을 시키며 단계 관찰.
- 함정: 한 번에 완벽을 기대 → 반복이 정상임을 납득.
- 분량: 6p · 원천: #5

## Part 2. 길들이기 — 내 프로젝트로 (2~3일 차)

### 2-1. CLAUDE.md 첫 작성 — AI에게 규칙 알려주기
- 학습 목표: 프로젝트 메모리 파일을 만들어 말투·규칙을 고정한다.
- 핵심 개념: CLAUDE.md, 프로젝트 컨텍스트.
- 실습: "한국어로 답해 줘" 등 3줄짜리 CLAUDE.md 만들기.
- 함정: 너무 길게 씀 → 짧게 시작 원칙.
- 분량: 8p · 원천: #6, #8

### 2-2. 슬래시 명령과 단축키 — 손이 빨라진다
- 학습 목표: 자주 쓰는 `/` 명령과 단축키를 손에 익힌다.
- 핵심 개념: 슬래시 명령, 단축키.
- 실습: `/help`, 입력 패턴 12가지 중 5개 따라 하기.
- 분량: 7p · 원천: #10, #112

### 2-3. 파일을 같이 고치기 — 보고, 고치고, 되돌리기
- 학습 목표: 변경을 확인하고 마음에 안 들면 되돌린다.
- 핵심 개념: 파일 편집 워크플로, 체크포인트.
- 실습: 한 파일 수정 → 되돌리기.
- 함정: 무서워서 승인 못 함 → 되돌릴 수 있다는 안심.
- 분량: 8p · 원천: #11

### 2-4. Plan 모드 — 일 시키기 전에 계획부터
- 학습 목표: 큰 일을 시키기 전에 계획을 받아 본다.
- 핵심 개념: Plan 모드(맛보기).
- 실습: "할 일 목록 앱 계획 세워 줘" → 계획 검토.
- 분량: 6p · 원천: #13

### 2-5. Git, 무섭지 않게 — 저장하고 되돌리는 안전벨트
- 학습 목표: 작업을 저장(커밋)하고 안전하게 되돌린다.
- 핵심 개념: Git 커밋(개념 최소화).
- 실습: 변경 → 커밋 한 줄 요청.
- 함정: Git 용어 공포 → '저장 지점' 비유.
- 분량: 8p · 원천: #14
