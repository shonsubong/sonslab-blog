# 1-3. 첫 5분 — 말 걸고, 시키고, 확인하기

> 학습 목표: 자연어로 시키고 결과를 받아 본다.
> 선수 지식: 1-2(설치 완료). · 원천: manifest #4

설치를 마쳤다면 까만 창에 `claude`를 치고 들어와 있을 것이다. 이제 진짜
첫 대화를 한다. 5분이면 된다.

## 1단계 — 말 걸기

먼저 가볍게 말을 걸어 보자. 이렇게 친다.

```
지금 이 폴더에 뭐가 있는지 알려 줘.
```

Claude Code가 폴더를 살펴보고 한국어로 답한다. 명령어를 외울 필요가 없다.
궁금한 걸 그냥 물으면 된다. 이게 핵심이다.

## 2단계 — 시키기

이번엔 일을 시킨다. 작은 파일 하나를 만들어 달라고 해 보자.

```
이 폴더에 hello.txt 파일을 만들고, 안에 "첫 줄을 적었다"라고 써 줘.
```

여기서 잠깐 멈추는 장면이 나온다. 화면에 **"이 파일을 만들어도 될까요?"**
같은 확인 창이 뜬다. 당황하지 말자. 다음 단계에서 설명한다.

## 3단계 — 승인하기 (멈칫하는 그 순간)

Claude Code는 당신 컴퓨터에서 뭔가를 바꾸기 전에 **항상 먼저 묻는다.**
파일을 만들거나, 고치거나, 명령을 실행하기 직전마다 그렇다. 이건 안전장치다.

확인 창에는 보통 이런 선택지가 있다.

- **예(한 번 허용)**: 이번 작업만 진행한다.
- **항상 허용**: 비슷한 작업은 앞으로 묻지 않는다. (익숙해진 다음에 쓰자)
- **아니오**: 하지 않는다. 다른 방식을 말해 주면 된다.

지금은 **예**를 고르자. `hello.txt`가 만들어진다.

> **막히면** — 무슨 작업인지 모르겠는데 승인하라고 하면, 일단 **아니오**를
> 누르고 "방금 뭘 하려던 거야? 쉽게 설명해 줘"라고 물어보자. 이해한 다음
> 승인해도 늦지 않다. 모르면 거절. 이게 안전하게 쓰는 법이다.

## 4단계 — 확인하기

정말 만들어졌는지 보자.

```
방금 만든 hello.txt 내용을 보여 줘.
```

"첫 줄을 적었다"가 그대로 나오면 성공이다. 방금 당신은 컴퓨터에게 일을
시키고, 그 결과를 두 눈으로 확인했다. 5분 전과 다른 사람이 됐다.

## 방금 무슨 일이 일어난 건가

정리하면 이 흐름이다.

1. **말한다** — 한국어로 원하는 걸 적는다.
2. **묻는다** — Claude Code가 "이렇게 해도 되냐"고 확인한다.
3. **승인한다** — 당신이 허락한다.
4. **확인한다** — 결과를 본다.

이 네 박자가 앞으로 하는 모든 일의 기본 리듬이다. 가계부 앱을 만들든, 사진
이름을 바꾸든, 전부 이 리듬 위에서 돌아간다.

## 정리

- 명령어 대신 **그냥 한국어로** 물어보고 시킨다.
- 컴퓨터를 바꾸기 전엔 **항상 먼저 묻는다.** 모르면 거절하고 되물어라.
- 말하기 → 묻기 → 승인 → 확인. 이 네 박자가 전부다.

아주 쉽게 들여다본다.
