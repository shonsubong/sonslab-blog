# 1-1. Claude Code가 뭐길래

> 학습 목표: 이 도구가 무엇을 대신해 주는지 한 문장으로 말할 수 있다.
> 선수 지식: 없음. · 원천: manifest #1

## 한 문장으로

Claude Code는 **사람 말로 시키면 컴퓨터 일을 대신 해 주는 AI**다. 그게 전부다.

조금 더 풀면 이렇다. 파일을 만들고, 코드를 쓰고, 잘못된 곳을 고치고, 프로그램을
실행해 보고, 결과를 확인하는 일 — 원래는 개발자가 손으로 하던 이 과정을, 이제
당신이 한국어로 부탁하면 알아서 한다.

## 비유 하나

요리를 떠올려 보자. 예전의 코딩은 재료를 직접 사고, 칼질을 하고, 불 세기를
맞추는 일이었다. 레시피(문법)를 다 외워야 했다. Claude Code는 옆에 선
요리사다. "김치찌개 끓여 줘, 좀 덜 맵게"라고 말하면 알아서 한다. 당신은
맛을 보고 "조금 더 끓여"라고 답하면 된다.

칼질을 못 해도 된다. 무엇을 먹고 싶은지만 알면 된다.

## 이런 걸 할 수 있다 (비전공자 실제 사례)

- **가계부 앱**: "수입과 지출을 적고 월별 합계를 보여 주는 앱 만들어 줘."
- **자료 정리**: "이 폴더의 사진 파일 이름을 날짜순으로 바꿔 줘."
- **문서 작업**: "이 엑셀을 읽어서 보고서 초안을 만들어 줘."
- **공부**: "이 코드가 무슨 일을 하는지 한 줄씩 설명해 줘."
- **간단한 웹페이지**: "내 소개 페이지를 만들어 줘. 사진 넣을 자리도."

이 중에 개발자만 할 수 있는 건 없다. 무엇을 원하는지 말할 수 있으면 충분하다.

## "개발자만 쓰는 거 아니야?" — 가장 흔한 오해

아니다. 오히려 코딩을 모르는 사람일수록 효용이 크다. 개발자는 이미 손이
빠르니 도구가 시간을 조금 줄여 줄 뿐이다. 하지만 당신에게는 **0을 1로** 만들어
준다. 못 하던 일을 하게 해 준다. 그 차이가 훨씬 크다.

이 책의 독자 중 다수는 마케터, 기획자, 학생, 자영업자다. 이들이 자기 일에
필요한 작은 도구를 직접 만들어 쓴다. 당신도 곧 그렇게 된다.

## 그럼 공짜인가, 안전한가

비용과 안전이 궁금할 것이다. 짧게만 답하면, **시작은 부담 없이** 할 수 있고,
**당신 허락 없이는 함부로 바꾸지 않는다.** 파일을 고치기 전에 매번 "이렇게
바꿔도 될까요?"라고 묻는다. 자세한 비용 이야기와 안전장치는 2부와 4부에서
다룬다. 지금은 "물어보고 한다"만 기억하자.

## 정리

- Claude Code = 사람 말로 시키는 AI 코딩 도구.
- 무엇을 원하는지만 알면 된다. 문법은 몰라도 된다.
- 비전공자에게 효용이 더 크다. 못 하던 일을 하게 해 주니까.
